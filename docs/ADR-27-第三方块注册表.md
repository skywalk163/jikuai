# ADR-27 · 第三方块注册表规范（v0.15.0 W22）

- 状态：Accepted
- 日期：2026-08-10
- 决策者：项目维护者
- 落地环节：v0.15.0 W22
- 相关：ADR-15（块生态架构）、ADR-25（语义选块）、ADR-26（类型词表）

---

## 1. 背景

v0.14.0 的块生态仅支持内置 `stdlib/blocks/` 下的块。用户与社区贡献者无法在
不修改仓库的前提下发布、安装和使用第三方块。随着块数突破 100，需要一套注册表
机制让第三方块能被 CLI 发现、被 `retrieval` 检索到，同时保证内置块不被覆盖。

## 2. 决议

### 2.1 目录布局

第三方块的物理布局：

```
<块根>/blocks/<命名空间>/<领域>/<块名>/块.json
```

`块根` 由环境变量 `JIKUAI_PKG_ROOTS` 指定，语义为**块目录根**（与
`blocks_root()` 同层级——直接是 `blocks/` 目录）。多路径以 `os.pathsep`
分隔（Windows 用 `;`，POSIX 用 `:`）。不设则只扫内置。

内置块（`stdlib/blocks/`）的布局不变：

```
stdlib/blocks/<领域>/<块名>/块.json
```

### 2.2 命名空间

- 块的完整引用是 `<命名空间>.<领域>.<块名>`。
- **内置块命名空间为空串**，引用保持 `blocks.数据.求和`。
- 第三方块引用为 `blocks.社区.数据.方差`（命名空间 `社区`、领域 `数据`、
  块名 `方差`）。
- 命名空间从目录结构推断：extra root 下第一级子目录名即为命名空间。
- 命名空间**不写进 `块.json`**，由扫描时根据路径注入到 `BlockMetadata._data`。

### 2.3 合并规则

- 内置块与第三方块**同名不失败、但内置优先**。
- `generate_index` 先放内置、再追加第三方（重名则 warn + 跳过）。
- **同一命名空间内块名必须唯一**。跨命名空间允许同名。
- G13（导出名全局唯一）**跨命名空间校验**——无论哪个命名空间，导出名全局
  不重名。

### 2.4 索引格式

`索引.json` 条目新增 `命名空间` 字段（内置为空串 `""`）：

```json
{
  "名称": "方差",
  "命名空间": "社区",
  "领域": ["数据"],
  "层级": 0,
  "描述": "...",
  "输入": [...],
  "输出": {...},
  "导出": ["方差"],
  "稳定性": "stable"
}
```

### 2.5 稳定性传递规则（本次只写规范不实现校验）

- stable 内置块不得依赖 experimental 第三方块。
- 违反时在 `_validate` 阶段告警（留给后续 W23+ 实现）。

## 3. 实现

### 3.1 `blocks.py` 改动

- `_extra_roots()`: 读 `JIKUAI_PKG_ROOTS` 环境变量，按 `os.pathsep` 拆分，
  过滤空串和不存在的目录。
- `_infer_namespace(block_meta_path, root)`: 对内置根返回 `''`；对 extra root
  计算相对路径的第一段为命名空间。
- `scan_blocks(root=None, roots=None)`: 向后兼容；支持多根扫描。
- `_INDEX_ENTRY_KEYS` 追加 `'命名空间'`。
- `to_index_entry()` 输出含 `命名空间`。
- 全局块名唯一检查改为同命名空间内唯一。

### 3.2 门禁影响

| 门禁 | 变化 |
|------|------|
| G12  | 无变化（只校验内置块索引） |
| G13  | 跨命名空间导出名唯一 |
| G14  | 仅对内置块强制精度，第三方块走宽松兼容路径 |

## 4. 后果

- `索引.json` 格式版本不变（`0.12.0`），条目多一个可选字段 `命名空间`。
  消费方（Retriever、CLI）对缺失字段容错。
- 环境变量 `JIKUAI_PKG_ROOTS` 是用户侧唯一配置入口，零代码即可接入第三方块。
- 未来若需包管理器自动安装，只需让安装器把块放到约定目录并追加环境变量。

## 5. 决策记录

| 备选 | 理由 |
|------|------|
| 命名空间写进 `块.json` | 发布者需手动填写，易出错；目录结构已隐含 |
| `JIKUAI_PKG_ROOTS` 指向包根再拼 `/blocks/` | 多一层间接，代码改动更大 |
| 当前方案：环境变量直接指向块根 | 与 `blocks_root()` 同层级，代码改动最小 |
