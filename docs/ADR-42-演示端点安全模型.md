# ADR-42 · 演示端点安全模型

- 状态：已接受（2026-08-20，v0.28.0 W164）
- 关联：[`路线图-v0.26-v0.28.md`](路线图-v0.26-v0.28.md) §七、
  [`v0.28.0-WBS.md`](v0.28.0-WBS.md) W164-W166、[`安全边界.md`](安全边界.md)、
  `tools/web/server.py`（旧的本机开发服务，**本 ADR 不改它**）

## 背景

赛题交付物第一条要「可运行 Demo **或在线访问链接**」。现有
`tools/web/server.py` 无任何鉴权，`/api/跑` 在服务进程内 `run_source` 执行调用方
提交的极快源码——极快经 `蟒:` 桥可调 Python，等价于**任意代码执行**。它的文件头
`SAFETY_NOTICE` 自己明令「勿绑 0.0.0.0、勿反代、勿暴露公网」，AGENTS.md §三同样点名。

因此不能把旧服务挂出去做演示。本 ADR 定义一个**新开的、可以放心给人点的**演示端点。

## 决策

新开 `tools/web/demo_server.py`，与旧服务**完全独立**（独立模块、独立测试、独立门禁
G24）。三个端点：

- `POST /演示/问` —— 入参 `{需求}`，出参 = `jk 块 规划` 的上下文包（**离线，一个模型
  都不碰**）。
- `POST /演示/跑` —— 入参**只收** `{方案}`。出现 `源码` 键直接 400。
- `GET  /演示/白名单` —— 回当前允许的块清单，供前端与审计自查。

### 四道闸（全部默认拒绝）

1. **鉴权**：`Authorization: Bearer <token>`。Token 只从环境变量 `JIKUAI_DEMO_TOKEN`
   取，**命令行不收 key**（沿用 v0.27.0 `JIKUAI_PLANNER_TOKEN` 的既有拍板）。
   未设该变量时端点**拒绝启动**（退 1 + 中文理由），不生成随机默认 Token 打日志。
   比较用 `hmac.compare_digest`（防时序侧信道）。
2. **块白名单**：只放行制造域指标/引擎块 + 明确列举的少数通用块。白名单是模块级
   常量 `允许块`。方案任何一步不在白名单 → 400，回不在白名单的那一步位置。
   这一条挡的是「白名单外的块（如 `蟒:` 桥相关、文件写入类）被组进源码执行」。
3. **执行隔离**：`组` 出源码后用 `subprocess` 起**独立解释器**跑，带 `timeout`；
   超时 → 504。**绝不在服务进程内 `run_source`**——那正是旧服务的病根。子进程只读
   数据集、无写权限意图（靠闸 4 限制路径）。
4. **数据集只读**：方案里出现的文件路径参数必须 `realpath` 后落在
   `赛题/chatbi/数据集/` 之内（照抄旧服务 `_解析静态路径` 的 `realpath` + `commonpath`
   三道闸口径），越界 → 400。挡 `../` 逃逸、绝对路径、符号链接逃逸。

体积闸沿用旧服务常量口径（`MAX_BODY` / `MAX_PLAN_BYTES`），不重造。

## 被否的备选

- **给旧 `server.py` 加一个「安全模式」flag**：否。危险能力（收源码、进程内执行、
  无白名单）与安全能力在同一 handler 里靠 flag 区分，一次配置失误就穿透；两套代码
  物理隔离才是可审计的边界。
- **用 `RestrictedPython` / AST 白名单在进程内执行**：否。极快经 `蟒:` 桥落到
  CPython，进程内任何「受限执行」都要挡住整个 Python 逃逸面，工程量大且易漏。
  子进程 + 超时 + 无额外权限是更小、更可验证的信任边界。
- **本轮就做公网部署（反代 + HTTPS + 限流）**：否，推 v0.29.0。本轮只做到「本机可跑
  的安全端点」这一档。赛题「在线访问链接」一栏**如实空着**——拿本机端点冒充在线链接，
  安全化就白做了（见 WBS §五反向度量）。

## 「怎么验证它真在守」（G24 行为断言）

G24 起一个 `port=0` 实例，真发四类请求断言状态码 + 中文理由关键词：
无 Token → 401 / 带 `源码` 键 → 400 / 白名单外块 → 400 / 路径逃逸 → 400。
另用 `tmp_path` 造四份改坏副本（删鉴权判断 / 删白名单过滤 / 换回进程内执行 /
放开路径闸），逐一证明 G24 抓得到。静态断言另扫 `demo_server.py` 不出现
`run_source`/`exec`/`eval`、无收 `源码` 键的路径、Token 只从 `os.environ` 取。

理由：v0.27.0 G23 的教训是「守卫绿 ≠ 守卫在守」——只静态时把闸的循环体注释掉照样
绿，只行为时把校验器改成「凡不认识就拒」也能全场景过而白名单已没了。故两套都要。
