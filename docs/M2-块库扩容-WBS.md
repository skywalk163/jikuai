## 2. 开工前必须知道的六个坑

这几条是勘察出来的硬事实，不先处理会让整批返工。

1. **极快没有中缀运算符**。`+ - * /` 一律是前缀动词：`加 减 乘 除 取余 幂 整除 绝对值 负`。复利写成 `乘 赵本金 幂 加 1 赵利率 赵期数`。
2. **没有内建的四舍五入 / 取整**。`四舍五入`、`向上取整`、`保留N位` 都不存在。财务块的分位处理只有两条路：用内建 `人民币` / `￥` 字面量（内部 `Decimal` + `ROUND_HALF_UP`，正合中国会计惯例），或给块加 `.py` 背衬（ADR-16 §3.3 混合模块，参考 `stdlib/blocks/数据/存文`）。**B1 的 `保留分` 块就是专门用来兜这件事的，其余财务块一律依赖它，不各自造轮子。**
3. **内建 `读取` / `写入` 是空壳**，运行期报「未知动词」。要文件 I/O 必须走 `blocks.数据.载入` / `blocks.数据.存文`。
4. **变量名首字必须是百家姓姓氏**（`赵钱孙李…`），且整体要词法原子。`赵列表` 会被切成 `赵`+`列`(VERB)+`表`，所以现有块统一写 `赵数值` / `赵项表`。形参命名前先过一遍原子性检查（见 §6）。
5. **保留字不能做导出名**：`整数 小数 字符串 布尔 列表 字典 人民币 日期`，以及全部内建动词（`求和 最大 最小 平均 加 减 …`）。所以块目录名可以叫 `复利`，但导出名要另取（`滚利`）——目录名与导出名分离是既有惯例，不是我新造的。
6. **`测试.jk` 目前没有 runner**。`validate_block` 只检查文件存在（缺失仅告警），CI 从来没执行过任何 `stdlib/blocks/**/测试.jk`。这意味着 102 个块的 `.jk` 里可以藏着运行期错误而 CI 全绿。**B0 必须先补这个 runner**，否则 B1-B3 的交付质量无法验证。

## 4. B1 · 财务领域（13 块）

与既有块的边界：`中文` 域已有 `金额雅写` / `数字中文` / `金额报表`，那三个是**金额的表现层**（数→中文大写）。财务域做的是**金额的计算层**，零重叠。

### L0 原子块（10）

- `保留分` → 导出 `圆分`：数 → 数。`ROUND_HALF_UP` 保留 2 位。**带 `.py` 背衬**，是其余财务块的公共依赖。
- `单利` → 导出 `息金`：本金, 年利率, 年数 → 数
- `复利` → 导出 `滚利`：本金, 年利率, 年数 → 数。用 `幂`
- `贴现` → 导出 `折现`：终值, 贴现率, 期数 → 数
- `年金` → 导出 `年供`：本金, 年利率, 期数 → 数。等额年金公式
- `个税` → 导出 `缴税`：月收入 → 数。中国大陆七级累进 + 5000 起征点
- `增值税` → 导出 `增税`：含税价, 税率 → 列表 `[不含税价, 税额]`
- `折旧` → 导出 `折价`：原值, 残值, 年限 → 列表（直线法逐年折旧额）
- `换汇` → 导出 `兑值`：金额, 汇率 → 数
- `分期` → 导出 `期供`：总额, 期数 → 列表（等额分摊，余数落最后一期，不丢分）

### L1 聚合块（3）

- `等额本息` → 导出 `房贷`：本金, 年利率, 月数 → 列表 `[月供, 总利息, 总还款]`。依赖块 `年金` `保留分`
- `税单` → 导出 `税据`：月收入 → 列表 `[收入, 个税, 税后, 税额大写]`。依赖块 `个税` `金额雅写`
- `投资表` → 导出 `收益`：本金, 年利率, 年数 → 列表 `[本息, 利息, 本息大写]`。依赖块 `复利` `金额雅写`

## 5. B2 · 历法领域（13 块）

与既有块的边界：`中文` 域已有 `农历` / `干支` / `属相表` / `阴历日程`，那四个是**中国文化表现层**（公历→农历/生肖/干支字符串）。历法域做**日期数学**，零重叠。

多日期入参统一用列表（`赵起 = 列 2026 8 9`），避免 6 个位置参数那种不可读的签名。

### L0 原子块（10）

- `闰年` → 导出 `闰判`：年 → 布尔
- `月长` → 导出 `月天`：年, 月 → 数
- `日序` → 导出 `序日`：年, 月, 日 → 数（绝对日序，类比 `date.toordinal`，是 `日差` 的基础）
- `日差` → 导出 `天距`：起日列表, 止日列表 → 数。依赖 `日序`（严格说这块是 L1，按层级标签算 1）
- `周几` → 导出 `星期`：年, 月, 日 → 字符串（"星期三"）
- `挪日` → 导出 `移日`：年, 月, 日, 天数 → 列表 `[年, 月, 日]`
- `周岁` → 导出 `实岁`：生日列表, 今日列表 → 数（按月日是否已过修正，不是简单年份相减）
- `节气` → 导出 `气候`：年, 序号 → 字符串（24 节气名 + 该年日期）
- `时辰` → 导出 `辰名`：小时 → 字符串（子丑寅卯…十二时辰）
- `旬日` → 导出 `旬序`：日 → 字符串（上旬/中旬/下旬）

### L1 聚合块（3）

- `纪年` → 导出 `岁次`：年 → 列表 `[干支, 生肖]`。依赖块 `干支` `属相表`（跨域依赖，`依赖块` 用叶名）
- `生辰` → 导出 `命帖`：年, 月, 日, 时 → 列表 `[农历日期, 干支, 生肖, 时辰]`。依赖块 `农历` `干支` `属相表` `时辰`
- `历表` → 导出 `月历`：年, 月 → 列表（该月每日的 `[日, 星期]`）。依赖块 `月长` `周几`

## 9. 已知风险

- **检索精度稀释**（高）：块数翻倍，同义词表和领域先验没跟上的话 Recall@3 会掉。缓解：B4 第 4、5、6 步；如果 bench 掉到 75% 以下，先补同义词表而不是放宽门禁。
- **个税/增值税税率表会过时**（中）：写死在 `.jk` 里的税率表迟早失效。缓解：`块.json` 的 `描述` 里标注适用年份，`稳定性` 标 `experimental`，别标 `stable`。
- **财务精度**（中）：不走 `人民币`/`Decimal` 而用浮点会出 `0.1+0.2` 那类问题。缓解：`保留分` 作为强制公共依赖 + `测试.jk` 里放分位断言。
- **跨域依赖**（低）：历法域的 `纪年`/`生辰` 依赖中文域的块。`依赖块` 字段用叶名，G11 的双向一致性校验能覆盖，但要确认 `validate_block` 对跨域依赖没有额外限制——**B2 开工前先用一个块试通**。
