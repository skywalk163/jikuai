## M1（W1-W4）· 类型系统细化

### W1 · ADR-26 类型词表规范落稿

**目标**：把「元素类型 / 元数 / 子类型」写死进 `块.json` schema，同时提出 `列表<数>` / `元组[数, 数, 字符串]` 的书写形式。

**动作**
- `docs/ADR-26-类型词表规范.md` 新增。定义：
  - 单类型：`数 / 字符串 / 布尔 / 函数 / 任意`
  - 同质容器：`{"类型": "列表", "元素类型": "数"}` / `{"类型": "字典", "键类型": "字符串", "值类型": "任意"}`
  - 异质元组：`{"类型": "元组", "元数": ["数", "数", "数", "字符串"]}`（用于 `批量统计` / `税单` 这类固定形状返回）
  - 子类型规则：`列表<T>` <: `列表`；`元组[T1..Tn]` <: `列表`（长度已知）；`T` <: `任意`
- `src/jikuai/pkg/blocks.py`：`_validate` 扩容支持新字段，向后兼容旧的 `{"类型": "列表"}`（未标细化视为 `列表<任意>`）
- 单测 `tests/test_blocks_type_schema.py`：合法/非法字段各 3-5 条

**DoD**
- ADR-26 落稿；`_validate` 通过对新旧格式的样本 JSON
- pytest 全绿（未回填的块保留旧字段，仍合规）

**依赖**：无

### W3-W4 · 类型对齐粘合器落地

**目标**：`glue.py` 从模板合成升级到类型图驱动。给定选块方案，自动推断 `赵果i → 赵果j` 的传参链。

**动作**
- `tools/ai-bridge/glue.py` 新增 `TypeGraph` 类：
  - 节点 = 已产出变量（附带类型）；边 = 「A 的输出类型可喂 B 的第 k 个入参」

- `tools/ai-bridge/bench_glue.py`（新）：跑评测集出 `自动链式命中率 / 语义荒谬率 / 拒绝质量`
- `tests/test_glue_type.py`：单测覆盖 8 种类型对齐边界

**DoD**
- 自动链式命中率 ≥60%（新评测集）

## M2（W5-W8）· L2 块 + 元数据补强

### W5-W6 · 三个 L2 块

**目标**：验证多级聚合，覆盖财务 + 中文 + 混合三种典型。

**动作**（三块并行）
- `stdlib/blocks/财务/工资条/`（L2，聚合 `税单+金额报表+周岁`）：输入月薪+出生日期，输出结构化工资条含中文金额
- `stdlib/blocks/财务/月结单/`（L2，聚合 `分期+等额本息+保留分+金额雅写`）：贷款额+期数+年利率，出月供+总利息+期供明细
  - **W12 修正**：原计划聚合 `复利`，但「复利滚存 ÷ 期数」不是等额本息——12 万/12 期/6% 会算出月供 10600，真值 10327.97（偏差 2.6%）。用户裁决金融语义优先，改聚合 `等额本息`（月率 = 年率 ÷ 12 的年金）。
- `stdlib/blocks/中文/用户档案/`（L2，聚合 `姓名拆分+身份证+地址剖解+周岁`）：输入身份证+姓名+地址，出结构化档案
- 每块三件套齐（`块.json` + `<名>.jk` + `测试.jk`），层级=2，`依赖块` 写叶名
- `src/jikuai/pkg/blocks.py` 的 `_validate` 支持层级 ≥ 2（当前允许 ≥0，验证下）
- 索引重生成后 102→105 块

**DoD**
- 3 块单独测试.jk 全过 `jk 块 校验` 与 `jk <路径>/测试.jk`
- 索引一致；G11/G12/G14 门禁绿；pytest 全绿

**依赖**：W2

### W11 · `embed_query.py` sidecar + 神经路径接入 CLI/REPL

**目标**：让 `--向量` 不再需要用户手工生成 JSON——CLI/REPL 自己 subprocess 拉一次向量。

**动作**
- `tools/ai-bridge/embed_query.py`：单文件，读 stdin 一行需求 → 用 sentence-transformers 出向量 → 写 stdout JSON 数组。启动开销一次 ~10s（模型加载），但可以常驻（`--daemon` 模式起本地 unix socket 或 stdin 逐行）
- `src/jikuai/pkg/blocks_cli.py` `_cmd_select` / `repl_session.py`：新增 `--神经` 开关，环境变量 `JIKUAI_AI_EMBED_CMD` 指向 sidecar；未装 sidecar 时保持启发式

- `tests/test_blocks_cli.py` 加 `--神经` 缺 sidecar 时降级测试（mock 一个失败的 subprocess）

**DoD**
- 装了 requirements-ai 时 `jk 块 选 "xxx" --神经` 走神经路径且 `[神经]` 标签出现
- 未装时优雅降级到启发式 + 一行提示
