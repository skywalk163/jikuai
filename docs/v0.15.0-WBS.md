## M5（W17-W20）· Web UI 零依赖

### W17 · 只读服务骨架（标准库 http.server）

**目标**：本地起服务、返回 JSON。**严禁 `pip install` 除 requirements-ai 之外任何东西**。

**动作**
- `tools/web/server.py`（新）：`http.server.ThreadingHTTPServer` + 手写 `BaseHTTPRequestHandler`
  - `GET /api/blocks` → 返回 `索引.json`
  - `POST /api/选` → body `{需求, top?, 神经?}` → 走 `retrieval.retrieve`
  - `POST /api/组` → body `{方案}` → 走 `glue.synthesize`
  - `POST /api/跑` → body `{方案}` → 组 + evaluator 跑，返回 `{stdout, stderr, 返回值}`
- 所有 API 返回复用 W20 定义的统一 schema
- 5000 端口，默认只监听 127.0.0.1
- `tools/web/README.md`：起服务的三行命令 + 每个端点的 curl 示例

**DoD**
- `python tools/web/server.py` 起服务，curl 四个端点全 200
- **无新增 pip 依赖**
- 单测 `tests/test_web_server.py`：requests-less（用 `http.client`）覆盖 4 端点各 1 条

**依赖**：v0.14.0 的三段式 CLI 已稳定

### W20 · 三通道统一 JSON 协议 · **硬门槛**

**目标**：CLI/LSP/Web 三边 API 复用同一份 schema。这一周不做新功能，只做**收敛**。

**动作**
- `docs/协议-三通道.md`（新）：定义三类 schema：
  - `候选` schema：`{名称, 领域, 层级, 描述, 分数, 路径}` —— 用于 `选` 返回、LSP executeCommand 结果、Web 卡片
  - `方案` schema：`{需求?, 共享?, 步骤: [{块, 领域, 导出名, 参数?, 说明?}], 打印?}` —— 三边 `组`/`跑` 共用
  - `执行结果` schema：`{stdout, stderr, 返回值, 耗时毫秒, 错误?}`
- `src/jikuai/service/`（利用已有 L3 层）新增 `schema.py`：schema 常量 + 校验函数（纯标准库 json，不引 jsonschema）
- `blocks_cli.py`、`glue.py`、`lsp/server.py`、`web/server.py` 全部改用 `schema.py`
- 单测 `tests/test_service_schema.py`：校验器正反 8 条

**DoD**
- 三通道 API grep 不到手写字段名，全部走 `schema.py`
- pytest 全绿；三通道端到端 demo 各跑一次结果字段一致
- 契约门禁绿

**依赖**：W15、W17、v0.14.0 W9

### W22 · ADR-27 第三方块注册表规范

**目标**：让别人的块能被内置块生态发现，但不覆盖内置块。

**动作**
- `docs/ADR-27-第三方块注册表.md`：
  - 布局：`极快_包/blocks/<命名空间>/<领域>/<块名>/`
  - 命名空间强制：块的完整引用是 `<命名空间>.<领域>.<块名>`；内置块命名空间为空（`blocks.数据.求和` 保持不变）
  - `索引.json` 合并规则：内置优先；同名冲突警告不失败
  - 稳定性传递：内置块可依赖 stable/experimental 第三方块；stable 内置块不得依赖 experimental 第三方块
- `src/jikuai/pkg/blocks.py`：
  - `scan_blocks` 支持 `roots` 列表，扫描 `blocks_root() + [极快_包/blocks/<命名空间>/*]`
  - `generate_index` 输出条目加 `命名空间` 字段（内置为空）
  - 复用 G12/G13/G14 门禁，跨命名空间校验
- `tests/test_blocks_third_party.py`：造两个第三方块（tmp_path），验证扫描、合并、命名空间隔离

**DoD**
- 第三方块能被 `jk 块 列表` 看到并被 `retrieval` 检索到
- 内置与第三方同名不冲突；命名空间不同的同名块可以共存
