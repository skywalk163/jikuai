# 极快 JiKuai v0.16.0 WBS · 下三个月（M7-M9）

- 起草：2026-08-10
- 周期：W25-W36（3 个月）
- 主题：发布卫生归零 + 链式召回真度量 + L3 场景块 + LSP 二阶能力
- 前置：v0.15.0（LSP 补齐 + Web UI 零依赖 + 第三方块生态 + 三通道统一协议）
- 关联：`docs/v0.15.0-WBS.md`、`docs/v0.14-v0.15-复盘.md`（五、v0.16.0 待办候选）

**执行原则**

1. **W25/W26 是准入前置**：版本号三处不一致、损坏 commit、误建目录属于发布卫生债，不清完不开新功能。

4. 改块元数据必过 G12 → **必须重跑 embeddings**（本机 `HF_HUB_OFFLINE=1`）。

### W27 · `bench_retrieval_chain.py` · 链式召回真度量

**目标**：`评测集-链式.json`（30 用例）现在全 0.0，已定性为**评测 schema 与数据集 schema 不匹配**，不是回归。本周把它变成有意义的数字。

**背景**：`bench_retrieval.py` 用「候选块名 ∈ 期望名列表」判命中；链式集期望的是**多步块名序列**（如 `[个税, 金额雅写]`），单块召回天然打不中。

**动作**
- `tools/ai-bridge/bench_retrieval_chain.py`（新，**不改** `bench_retrieval.py`）：
  - 新指标 **步覆盖率**：`|检索出的块 ∩ 期望序列| / |期望序列|`
  - 新指标 **序列完整命中率**：期望序列全部出现在 top-K 的用例占比
  - 新指标 **顺序保真度**：命中的块在候选中的相对顺序与期望序列一致的比例（宽松版：只要求偏序）
  - 三臂对照（关键词 / TF-IDF / 神经）+ top-K 可配（K=3/5/10）
  - 神经路径连不上 embedding 时**降级 skip 而非报错**（CI 侧硬要求）
- 拆链式留出集 `评测集-链式-留出.json`（≥10 条，与调优集零重叠）—— 双集报数是硬规矩
- `docs/路线图-v0.16.0-检索.md`（或直接更新 memory `检索调优路线.md`）记录本轮基线

**DoD**
- 链式集三臂数字非零且可解释；调优集 + 留出集两套都出
- 留出集上神经步覆盖率 ≥ TF-IDF（若不成立，如实记录为证伪，不调参数刷分）
- 无 embedding 环境下 bench 优雅 skip

## M8（W29-W32）· L3 场景块 + Web 可写化

### W29 · ADR-28 · L3 聚合块规范

**目标**：v0.15.0 只有 3 个 L2 块，复盘已证「真到跨域场景 L2 数量偏少」。L3 是跨 L2 的场景块（`报销单` / `工资册`），先定规范再动手。

**动作**
- `docs/ADR-28-L3聚合块规范.md`：
  - **层级判定**：L3 = 依赖 ≥2 个 L2 块，或依赖 ≥1 个 L2 + 跨 ≥2 领域
  - **稳定性传递**（沿用 ADR-27 规则并向上扩展）：stable L3 不得依赖 experimental L2/L3
  - **依赖深度上限**：先定 L3（不开 L4），理由写清 —— 层级越深检索越难解释，先证明 L3 有价值
  - **`块.json` 扩展**：`依赖` 字段声明直接依赖的块全名，供 G13 做环检测
  - **参数收敛约定**：L3 的入参用类型词表（ADR-26）标注，让粘合器能自动链式
- `src/jikuai/pkg/blocks.py`：`层级` 校验扩展到 3；`依赖` 字段解析
- **G13 扩展**：加**依赖环检测** + 层级一致性（声明 L3 但只依赖 L1 → 拒）

**DoD**
- ADR-28 定稿；G13 能挡下依赖环与层级虚标
- `tests/test_blocks_l3_schema.py` 正反 ≥8 条
