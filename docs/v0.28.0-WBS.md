## 执行原则

1. **演示端点是「新开一个」，不是「给旧的打补丁」**。`tools/web/server.py` 原样保留、
   继续只作本机交互式工具，它的 `SAFETY_NOTICE` 一字不改。新端点独立模块、独立测试、
   独立门禁，两者不共享路由表。**理由**：旧服务的能力集（收源码、无白名单）本身就是
   危险面，在同一个 handler 里靠 flag 区分安全/不安全模式，一次配置失误就穿透。
2. **新端点默认拒绝，而不是默认放行**。无 Token → 401；块不在白名单 → 400；请求带
   `源码` 键 → 400（**不是忽略**）；执行超时 → 504。每一条都要有反例测试。
3. **鉴权 Token 只从环境变量取，命令行不收 key**（沿用 v0.27.0 `JIKUAI_PLANNER_TOKEN`
   的既有拍板）。未设环境变量时端点**拒绝启动**，不生成随机默认 Token 打在日志里。
4. **G24 必须「静态 + 行为」两套断言**（G23 的教训）：只静态时把白名单循环体注释掉照样
   绿；只行为时把校验器改成「凡不认识的块就拒」也能全场景过而白名单已没了。
5. **新门禁必造反例**，不少于 3 类，用 `tmp_path`。只测正例等于没有门禁。
6. **协议字段只从 `schema.py` 常量取**。新端点的请求/响应字段一律进常量，同步
   `docs/协议-三通道.md`，否则 G16 双向一致会红。
7. **分配块名必须「目录名 + 导出名」两个都验**（v0.26.0 W140-W142 三个块全栽在目录名上）。
   目录名进 `从 blocks.制造.<目录名> 导入 <导出名>。` 的点分路径段，必须过
   `check_module_segment_atomicity`；导出名另过 G13 全局唯一 + `check_export_atomicity`。
   **验完再动手写文件。**
8. **加块必刷索引 + embeddings，加/减 sidecar `.py` 必同步 `块背衬PY数`**。
   当前值 **37**，在 `scripts/check_wheel_contents.py:47`（与实测 37 一致，已核）。
   本机重跑 embeddings 要设 `HF_HUB_OFFLINE=1` `TRANSFORMERS_OFFLINE=1`。
9. **留出档只跑一次、不看 miss 明细**。`评测集-chatbi-留出.json` 5 条与
   `评测集-留出.json` 25 条同一条纪律。
10. **改块行为要同步影子实现**。纯 `.jk` 块（`窗口`/`月标`/`旬标`/`邻期关联`）在 pytest
    侧是用等价 Python 复现口径的（如 `tests/test_v0_26_0_w141_质量能耗.py` 的 `_截期`），
    改块必须一起改影子，否则测试绿而块已变。

**目标**：新开一个可以放心给人点的演示端点，把「提交任意源码 → 本机执行」这条路彻底堵死。

**动作**
- 新立 [`ADR-42-演示端点安全模型.md`](ADR-42-演示端点安全模型.md)：威胁模型（STRIDE 四条：
  未授权调用 / 任意代码执行 / 数据集越权读写 / 资源耗尽）、四道闸的设计与被否备选。

  `server.py` 的协议常量整元组解包写法）：
  - `POST /演示/问` —— 入参 `{需求}`，出参走 `规划` 上下文包（离线、不碰模型）。
  - `POST /演示/跑` —— 入参**只收** `{方案}`。出现 `源码` 键直接 400。
  - `GET /演示/白名单` —— 回当前允许的块清单，供前端与审计自查。
- 四道闸：
  1. **鉴权**：`Authorization: Bearer <token>`，Token 只从 `JIKUAI_DEMO_TOKEN` 取，
     未设则拒绝启动（退 1 + 中文理由）。比较用 `hmac.compare_digest`。

     方案里任何一步不在白名单 → 400 并回不在白名单的那一步位置。
  3. **执行隔离**：`subprocess` 起独立解释器跑 `组` 出来的源码，带 `timeout`，
     超时 → 504；**不在服务进程内 `run_source`**。
  4. **数据集只读**：方案里的路径参数必须落在 `赛题/chatbi/数据集/` 之下（`realpath` +
     `commonpath`，照抄 `_解析静态路径` 的三道闸口径），且只允许读。
- 体积闸沿用 `server.py` 既有常量口径（`MAX_BODY` / `MAX_PLAN_BYTES`）。
