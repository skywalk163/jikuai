## 一、被证实的判断

1. **「同进程起 HTTP 服务」的既有测试确实证不到位**。v0.27.0 W158/W159 的 25 条测试用的是
   `pytest` 进程内的 `HTTPServer`，共享同一个解释器、同一份 `sys.path`、同一套编码设置。
   拆成两个进程后立刻抓到两个只在跨进程才暴露的问题（见第三节 1、2 条）——这不是「补一份
   冗余证据」，是**证据类型不同**。
2. **参考端点必须「构造上诚实」，不能靠文档提醒**。`模型` 字段恒以 `参考端点·` 开头、
   装不下就回 **422 + 中文理由**而不是硬凑一个形状合法的方案、录像转投时把原 `模型` 值
   写进 `参考端点·录像转投（原：X）` 保留人工出处——这三条让「误当成模型验证过」在**数据里
   就看得出来**，不依赖读没读文档。
3. **归档另开目录是对的**。`真跑记录/` 与 `规划录像/` 物理分开，`规划录像/清单.json` 仍
   恰好 18 条——白名单可承载率的**分母一个没动**。这是 v0.28.0 W175 的教训直接复用。
4. **临时穿透与「不做公网部署」零冲突**。穿透只是本地演示手段，赛题「在线访问链接」栏
   照旧**如实空着**：v0.28.0 那两条诚实性守卫测试**一个字没改**，`test_v0_28_0_w178_交付物.py`
   24 passed 照旧绿。

## 二、被证伪或修正的判断

1. **「调小 `top` 就能造出装不下的包」——错。** 我原本用 `--top 1` 构造「候选装不下录像
   方案」的反例，结果 `表载入`/`窗口`/`产量汇总` 照样在候选里。根因是 v0.28.0 W174 的
   **语义层直取旁路不受 `top` 约束**（ADR-41 §9 写了，我没读进去）：它把骨架块追加到候选表
   末尾，`top` 只管词面那一段。修法是直接清空 `包[候选]` 造反例，并**补一条测试把这个行为
   钉住**（`test_调小top拦不住语义旁路所以承载不随top缩水`）——将来谁改旁路，这条先红。
2. **「反例用中文字面量更可读」——在令牌上不成立。** 用例表里写 `'令牌': '端点侧独有'`，
   端点自己的 ASCII 守卫直接拒绝启动，症状表现为「端点进程刚启动就退了」，与真正的 bug
   同形。令牌这类要进 HTTP 头的值**必须纯 ASCII**，已加 `test_端点侧令牌必须纯ascii` 守着。

## 三、必记单点（踩过的坑，按会不会再踩排序）

1. **`tools/ai-bridge/select.py` 遮蔽标准库 `select`**（本轮最贵的一坑，排查占了大半时间）。
   在该目录下起 HTTP 服务时，Python 把脚本目录塞进 `sys.path[0]`，`selectors` 于是导到这个
   同名文件。症状极具误导性：**bind 成功、URL 也打印出来了**，`serve_forever()` 才抛
   `AttributeError: module 'select' has no attribute 'select'` 进程即死，客户端只看到
   `WinError 10061 目标计算机积极拒绝`——看着像端口/防火墙问题。
   - 修法：把 `sys.path` 里的脚本目录挪到末尾，且这段**必须排在 `http.server`/`socketserver`
     导入之前**。我第一次修放在 import 之后，**没生效**——`selectors` 已经导入并缓存了。
   - 附带教训：`真跑_问.py` 起初没记端点侧 stderr，根因完全不可见。加了 `端点异常` 字段
     （端点进程尾声，含 `Traceback` 就记下）之后一眼就看到了。**跨进程台架必须把子进程
     stderr 一并归档**，否则失败信息在进程死的那一刻就丢了。
2. **PowerShell 5.1 吞不下内联 `python -c`** 的嵌套引号（本轮又栽两次，ParserError）。要么
   落成临时脚本用 `cmd /c` 跑，要么干脆写成 pytest 文件。
3. **跑全量必须 `cmd /c "set PYTHONUTF8=1&& set PYTHONIOENCODING=utf-8&& ..."`**，重定向也
   交给 `>`，不要用 PowerShell 的 `Out-File`/`Tee-Object`（成片假 UnicodeDecodeError）。
4. **门禁 G24/G25 通过时不打印任何行**（只有 G22/G23 打结论行）。所以**别拿输出里有没有
   `G24` 字样判成败**，要看进程退出码。本轮 `check_stdlib_contract.py` 退出码 0。
