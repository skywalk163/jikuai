# 极快 ↔ Python 互操作指南（v0.4.0 · M2）

极快提供**双向**的 Python 互操作能力：极快脚本里调用 Python 生态，Python
程序里嵌入并调用极快脚本。设计遵循 ADR-10/11/12。

---

## 一、极快 → Python（`蟒:` 前缀导入）

### 最小可运行示例

```
导入 蟒:math。
打印 math.sqrt(16)。          -- 输出：4.0

导入 蟒:json。
打印 json.dumps(列 1 2 3)。   -- 输出：[1, 2, 3]

导入 蟒:datetime。
定义 王时 = datetime.datetime(2026, 8, 7)。
打印 王时。                    -- 输出：2026-08-07 00:00:00
```

### 语法要点

- **必须**用 `蟒:` 前缀导入 Python 模块，与 `.jk` 模块在语法上区分：
  - `导入 数学。`      → 加载极快 `.jk` 模块
  - `导入 蟒:math。`   → 加载 Python 模块
- **Python 函数必须括号调用**（ADR-11）。免括号（元数驱动）写法只适用于
  中文动词：
  ```
  math.sqrt(16)。   -- 合法
  math.sqrt 16。    -- 报错：SYNTAX，「必须使用括号调用」
  ```
- 别名与点号模块：
  ```
  导入 蟒:math 作为 数学。   -- 绑定别名 数学
  导入 蟒:os.path。          -- 绑定顶层名 os，用 os.path.basename(...) 调用
  ```

### 类型映射表

| 极快 | Python | 说明 |
|------|--------|------|
| 整数 | `int` | |
| 小数 | `float` | |
| 字符串 | `str` | |
| 布尔 | `bool` | |
| 空 | `None` | |
| 列表 | `list` | 递归映射元素 |
| 字典 | `dict` | key 仅允许字符串 / 整数 |
| 人民币(RMB) | `Decimal` | 反向需 `人民币(...)` 显式包装 |
| 类实例 | opaque object | 原样过界，Python 侧不解构 |
| 类 | —— | **不跨界**（抛 TYPE 诊断） |
| 绑定方法 | —— | **禁止跨界**（DP-3，抛 TYPE 诊断） |

## 二、Python → 极快（`import jikuai`）

### 最小可运行示例

`脚本.jk`：
```
定义 王基数 = 100。

函数 平方 接收 数：
    返回 数 乘 数。
。

类 计数器：
    构造 接收 起始：
        自身.值 = 起始。
    。
    方法 增加 接收 步长：
        自身.值 = 自身.值 加 步长。
        返回 自身.值。
    。
。

导出 平方 王基数 计数器。
```

`宿主.py`：
```python
import jikuai

mod = jikuai.load("脚本.jk")     # base_dir 默认当前工作目录

print(mod.平方(3))               # 9        —— 调用函数
print(mod.王基数)                # 100      —— 读取变量

counter = mod.计数器(10)         # 实例化类
print(counter.增加(5))           # 15       —— 调用方法
print(counter.值)                # 15       —— 读取字段
```

### 三个入口

| 入口 | 用途 |
|------|------|
| `jikuai.load(path, base_dir=None)` | 加载 `.jk` 为模块对象，访问其 `导出` 的名字 |
| `jikuai.run_source(src)` | 直接执行一段极快源码，返回最后一条语句的值 |
| `jikuai.run_file(path)` | 执行整个 `.jk` 文件 |

- **`import jikuai` 不触发任何 `load`，也不建立全局可变状态。**
- **同一脚本 `load` 两次得到彼此独立的模块对象**（各自持有独立 Evaluator）。

### 异常翻译

```python
import jikuai

mod = jikuai.load("脚本.jk")
try:
    mod.会抛错(-1)
except jikuai.JiKuaiError as e:
    print(e.info.category.value)   # 中文类别
    print(e.info.message)          # 保留中文文案
```

- 极快侧 `JiKuaiError` 跨界 → Python 侧 `jikuai.JiKuaiError` 子类，保留
  中文文案与 `ErrorInfo`。
- Python 侧 `Exception` 跨界 → 极快侧 `ErrorInfo(RUNTIME)`，文案
  `Python 侧异常：<类名>：<message>`，**绝对路径已脱敏**。

## 三、安全边界

Python 桥是**新的攻击面**，本期实现以下约束：

1. **默认拒绝清单**（黑名单）：`os.system`、`subprocess.Popen`、
   `builtins.eval`、`builtins.exec`。命中即抛 RUNTIME 诊断。
2. **`jikuai.load` 路径校验**：拒绝绝对路径与 `..` 路径穿越，且解析结果
   必须落在 `base_dir` 内。
3. **异常不泄漏绝对路径**：跨语言异常文案里的绝对路径被替换为占位符。

> ⚠️ **绕过风险**：拒绝清单是**黑名单**而非沙箱。`蟒:` 导入本身不受限，
> 除清单外的任意模块/函数均可调用（如 `蟒:os` 的 `os.remove`、
> `蟒:shutil` 等）。若要在不可信环境中运行极快脚本，请在宿主 Python 侧
> 以最小权限封装后再暴露，而非依赖本清单。详见安全审计结论。
