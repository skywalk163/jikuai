# 极快 JiKuai · v0.14.0 发布说明

发布日期：2026-08-10 · 主题：类型系统细化 + 粘合器 + L2 块 + CLI/REPL 三段式

## 主要交付（W1–W12）

### M1 · 类型系统（W1–W4）

- **ADR-26 类型词表规范**（W1）：`列表<T>` / `元组[T1..Tn]` / `字典<K,V>` /
  `联合` / `任意` 一次到位；`_validate` 与索引 schema 向后兼容旧字段。
- **102 块类型标注回填 + G14 门禁**（W2）：拒绝裸 `列表` 无 `元素类型`、
  裸 `元组` 无 `元数`；`scripts/check_stdlib_contract.py` 串上 G14。
- **类型对齐粘合器**（W3–W4）：`tools/ai-bridge/glue.py::TypeGraph` 把选块
  方案里省略的 `参数` 按 ADR-26 类型图推断（自动链式），推不出的**给出
  可读拒绝理由**——例如「元组[数,数,数,数] 非 列表<数>，需人工拆包」，
  而不是硬塞一个类型不符的实参。配套 `评测集-链式.json`（30 条 · 应链 /
  应拒 / 边界）与 `bench_glue.py`。

### M2 · L2 块 + 元数据（W5–W8）

- **3 个 L2 块**（W5–W6，共 105 块）：`财务.工资条`（薪单）、
  `财务.月结单`（结单）、`中文.用户档案`（档帖）。三块横跨财务 / 中文 /
  历法域，验证多级聚合可用。
- **`导出` + `兼容` 字段**（W7）：`extract_exports` 优先读 `块.json.导出`，
  ADR-24 白名单注入不再必读 `.jk` 源；`兼容` 记录版本约束。105 块全回填。
- **G13 导出名全局唯一**（W8）：防止 `转义编码→转义` / `环境值→环境` 这类
  短名跨块碰撞；已在 105 块上过。

### M3 · CLI/REPL 三段式 + 发布（W9–W12）

- **三段式 CLI**（W9）：`jk 块 选 → 组 → 跑` 端到端可跑，同一份候选/方案/
  结果 JSON schema 三段共用。
- **REPL `需求` 元命令**（W10）：`极快> 需求 求个平均` 直接弹候选，选中
  后追加到当前 buffer 继续编辑。tab 补全 `需` 出 `需求`。
- **`embed_query.py` sidecar**（W11）：`--神经` 显式开启走 sentence-
  transformers 出查询向量；默认启发式保零运行时依赖。
- **10 个端到端 demo + 压缩比基准**（W12，本轮交付）：
  `examples/blocks/demo/` 新增 10 个覆盖财务 / 历法 / 中文 / 数据 / 网络
  的 `.jk` 端到端脚本；`tools/ai-bridge/bench_compress.py` 对每个 demo 报
  「不用块的裸写 token 数 vs 用块的方案 JSON token 数」。

裸写 = demo 自身编排 + 直接与传递依赖块的全部源码（含 `.py` 背衬）。
token 口径为 UTF-8 字节 ÷ 3.5 近似（未装 tiktoken 时的退化口径）。

「块已替你写好的算法」当零成本，是压缩比下界，不作门槛。

## 破坏性变更 / 迁移提示

- `块.json` 新增 `导出` / `兼容` 两个字段，105 块已回填；第三方块若手写过
  `块.json` 需补 `导出`（数组，元素须过 `check_export_atomicity`），否则
  G14 会拒；`兼容` 缺省视为无版本约束，不阻断。
- 索引 `_INDEX_ENTRY_KEYS` 加了 `导出`。读旧索引的老代码仍兼容（多字段
  静默忽略）；靠 `extract_exports` 走 `.jk` 兜底的路径未变。
- `列表` / `元组` 若在 `块.json` 里未标 `元素类型` / `元数`，G14 会拒——
  详见 ADR-26 §4 迁移指引。

## 依赖与兼容

- 运行时**零第三方依赖**保持不变。`tools/ai-bridge/embed_query.py` 走
  sidecar，AI 依赖（torch / sentence-transformers）仍在 `requirements-ai.txt`。
- `bench_compress.py` 本身零依赖：装 tiktoken 用精确 token；缺依赖或
  拉不到 cl100k_base 词表时退化到「字节 ÷ 3.5」近似并打警告。
