## 1. 目的

## 2. 偏差清单

### 偏差 A — `JiKuaiError` 的归属位置

- **原方案描述**：ADR-14 草案假设 `JiKuaiError` 定义在 `src/jikuai/errors.py`，与 `ErrorInfo`/`ErrorFormatter` 同模块
- **实际代码**：`JiKuaiError` 定义在 `src/jikuai/evaluator.py`；`src/jikuai/__init__.py` 通过 `from .evaluator import JiKuaiError` 导出；`src/jikuai/module_loader.py` 通过 `from .evaluator import JiKuaiError` 局部导入
- **影响面**：新建的 `diagnostics/` 包若 import `JiKuaiError`，将与 `evaluator` 产生循环依赖；`errors.py` 实际只包含 `ErrorCategory`/`ErrorInfo`/`ErrorFormatter`/`spelling_suggestion`/`_levenshtein`（约 80 行）
- **校正动作**：
  - ADR-14 删除「`JiKuaiError` 在 `errors.py`」的表述
  - `diagnostics/` 包硬约束：不得 import `evaluator` 模块
  - 需要 `JiKuaiError` 的场景（如 `module_loader`）继续从 `evaluator` 导入，不改动

### 偏差 B — `spelling_suggestion` 签名与能力

- **原方案描述**：US-M4-02 要求「编辑距离 ≤2 + 多并列候选」，假设可原地扩展 `spelling_suggestion`
- **实际代码**：`errors.py` 中 `spelling_suggestion(name, candidates, max_distance=1) -> Optional[str]` 返回单个候选字符串或 None；调用方（lexer/evaluator）直接消费该签名
- **影响面**：原地修改签名会破坏调用方与嵌入 API（`__all__` 导出了 `ErrorFormatter`，测试可能直接引用）
- **校正动作**：
  - 在 `diagnostics/spelling.py` 新增多候选函数（返回 `list[Suggestion]`，距离阈值 ≤2）
  - `errors.py` 的 `spelling_suggestion` 保留原签名与语义，作为兼容外壳
  - 新代码只调用 `diagnostics/spelling.py`，旧代码按原路径不动

### 偏差 C — stdlib 导出机制

- **原方案描述**：ADR-16 草案提议引入 `__导出__` 变量作为模块契约声明机制
- **实际代码**：真实机制是 `.jk` 源码中的**运行期 `导出` 语句**，由 `evaluator._current_exports` 收集，再交给 `module_loader.ModuleValue(name, env, exports, ev)` 构造模块对象。`ModuleValue.get()` 已实现「未导出即抛错」，消息为 `模块 {name} 未导出：{attr}`
- **影响面**：`__导出__` 变量机制属重复造轮子，且引入了运行时变量赋值之外的「魔法变量」概念，与极快「运行期语义」的设计哲学冲突
- **校正动作**：
  - ADR-16 决议改为「沿用现有 `导出` 语句 + 补错误码 + 补静态契约校验」
  - 删除 `__导出__` 变量的一切设计描述
  - `ModuleValue.get()` 的未导出路径补 `JK-E5002` 错误码
  - 新增静态契约校验脚本 `scripts/check_stdlib_contract.py`

### 偏差 D — AC-M4-03-03 已部分满足

- **原方案描述**：AC-M4-03-03 要求「模块找不到时，错误消息须包含模块名」，WBS 将此列为新增功能
- **实际代码**：`module_loader.resolve()` 抛出的异常消息已是 `找不到模块：{module_name}`，含模块名
- **影响面**：该 AC 的实现成本从「新增功能」降级为「补错误码 + 补测试」
- **校正动作**：
  - 该路径补 `JK-E5001` 错误码
  - 补充对应的单元测试断言结构化字段（code == "JK-E5001"）
  - WBS 工时从 0.5d 下调为 0.25d

## 3. 受影响的下游条目

- **ADR-14**：删除 `JiKuaiError` 归属 `errors.py` 的错误表述；增加 `diagnostics/` 不得 import `evaluator` 的硬约束
- **ADR-16**：整体机制从 `__导出__` 变量改为沿用 `导出` 语句；补错误码 `JK-E5001`/`JK-E5002`
- **US-M4-02**（拼写建议）：`spelling_suggestion` 不可原地改签名，须新增 `diagnostics/spelling.py`
- **US-M4-03**（模块错误消息）：AC-03 实现成本下调，仅需补码与测试
- **WBS**：T-M4-03（模块错误码）工时下调；T-M4-02（拼写建议）路径变更为新模块
- **测试计划**：拼写建议测试须覆盖新旧两条路径；模块错误测试断言 `JK-E5001` 结构化字段
