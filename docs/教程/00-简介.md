## 极快是什么

极快（JiKuai）是一门**面向中文母语者的编程语言**。它不是「把关键字翻译成中文的
壳」，而是把中文的语序、量词、标点直接做成语法，并把「中国国情」当成一等公民：

- 语句以中文句号 `。` 结束，块结构用中文冒号 `：` 开启
- 变量名**必须以百家姓开头**（赵钱孙李、周吴郑王……），一眼分清「这是我的变量」
- **逗号管道**：`列 1 2 3，皆乘2，只大于4，归加0。` 从左到右读，就是数据的流向
- **人民币字面量** `￥100.50` 按分精确存储，不是浮点数
- 内建**农历 / 干支 / 生肖 / 中文数字 / 大写金额 / 身份证与手机号校验**
- 标准库里有**简繁转换 / 中文排版 / 中文正则 / 成语库 / 中文分词**，零第三方依赖
- 和 Python 双向互操作：极快里 `导入 蟒:math`，Python 里 `jikuai.load("脚本.jk")`

## 适合谁

| 你是 | 极快能给你 |
|------|-----------|
| 编程初学者 / 学生 | 用母语描述逻辑，绕过英文关键字与语序的双重门槛 |
| 财务 / 行政 / 运营 | `￥` 精确金额、大写金额、报表脚本，不用怕浮点误差 |
| 中文内容从业者 | 排版规范化、简繁转换、分词、成语库，开箱即用 |
| Python 工程师 | 把极快当 DSL 嵌进现有项目，`jikuai.load` 一行接入 |

**不适合**：需要沙箱隔离地执行不受信任代码的场景。极快的 Python 互操作
**不是沙箱**，详见第 06 章与 `docs/安全边界.md`。

## 5 分钟能做什么

装好之后（第 01 章），5 分钟内你可以：

打印一句话 ——

<!-- run: true -->
<!-- expect: 你好，极快！ -->
```jikuai
打印 "你好，极快！"。
```

用管道算一串数 ——

<!-- run: true -->
<!-- expect: 24 -->
```jikuai
定义 赵表 = 列 1 2 3 4 5。
打印 (赵表，皆乘2，只大于4，归加0)。
```

算一笔账并转成中文大写 ——

<!-- run: true -->
<!-- expect: ￥148.40 -->
<!-- expect: 壹佰肆拾捌元肆角 -->
```jikuai
定义 赵单 = 列 ￥19.90 ￥8.50 ￥120.00。
定义 赵计 = 求和 赵单。
打印 赵计。
打印 大写金额 赵计。
```

查今天的农历 ——

<!-- run: true -->
<!-- expect: 丙午 -->
<!-- expect: 马 -->
<!-- expect: 丙午(马)年 八月十八 -->
```jikuai
打印 干支纪年 2026。
打印 生肖 2026。
打印 农历完整日期 2026 8 8。
```

## 本教程的代码片段标注约定

教程里的每个代码块都可能带 HTML 注释标注，供 CI 抽取执行
（`scripts/extract_tutorial_snippets.py` + `tests/test_v0_7_0_tutorial.py`）：

    <!-- run: true -->
    <!-- expect: 8 -->
    ```jikuai
    打印 加 3 5。
    ```

规则：

| 标注 | 含义 |
|------|------|
| `<!-- run: true -->` | 该片段纳入 CI 执行，断言退出码 0 |
| `<!-- expect: <文本> -->` | 断言归一化后的 stdout 等于该文本；写多条则按顺序拼成多行期望 |
| 无 `run` 标注 | 纯展示片段，CI 不执行（例如 shell 命令、Python 宿主代码、反例） |

也就是说：**凡是带 `run: true` 的片段，都是真跑过、输出核对过的**。
反例和「会报错的写法」一律不带 `run`，只作说明。

自己看一遍清单：

```
python scripts/extract_tutorial_snippets.py
python scripts/extract_tutorial_snippets.py --json
```
