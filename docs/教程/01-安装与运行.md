# 01 · 安装与运行

> 最小闭环第 1 步。读完这一章，你的机器上能跑起极快程序。

## 前置要求

- **Python ≥ 3.10**（`pyproject.toml` 的 `requires-python`）
- 一个支持 UTF-8 的终端。Windows 上 PowerShell / Windows Terminal 都可以
- 极快本体**零第三方依赖**：简繁转换、分词、成语库、排版都是内置数据表，
  不需要 opencc / jieba

检查 Python 版本：

```bash
python --version
```

## 方式一：pip 安装（推荐）

在仓库根目录：

```bash
pip install -e .
```

安装后得到两个等价的命令行入口（`pyproject.toml` 的 `[project.scripts]`）：

```bash
jk        --help
jikuai    --help
```

## 方式二：不安装，直接用 PYTHONPATH

仓库源码就能跑，适合只想试一下、或者在 CI 里跑：

```bash
# Linux / macOS
PYTHONPATH=src python -m jikuai examples/hello.jk
```

```powershell
# Windows PowerShell
$env:PYTHONPATH = "src"
python -m jikuai examples\hello.jk
```

> 本仓库的测试与本教程的 CI 都走这条路径（`PYTHONPATH=src` + `python -m jikuai`），
> 因此**不需要先 pip install** 也能验证全部示例。

## 三种运行方式

### 1. 执行一个文件

```bash
jk 我的程序.jk
# 等价于
PYTHONPATH=src python -m jikuai 我的程序.jk
```

文件必须是 **UTF-8 编码**。不是 UTF-8 时会直接报
`错误：文件编码不是 UTF-8` 并以退出码 1 结束。

### 2. 交互式 REPL

不带参数就进入 REPL：

```bash
jk
```

会看到横幅，然后逐行输入语句，输入 `退出` 或 `Ctrl+C` 结束：

```
极快> 打印 "你好"。
你好
极快> 定义 赵数 = 10。
极快> 打印 赵数 乘 3。
30
极快> 退出
```

REPL 支持多行输入（块语句自动续行）、历史、Tab 补全。

### 3. 从 Python 宿主里嵌入

```python
import jikuai

print(jikuai.run_source('打印 加 3 5。'))
```

详见第 06 章。

## 命令行选项

| 命令 | 作用 |
|------|------|
| `jk` | 进入交互式 REPL |
| `jk <文件.jk>` | 执行文件 |
| `jk -h` / `--help` / `帮助` | 显示帮助 |
| `jk -v` / `--version` / `版本` | 显示版本号 |

`jk -v` 输出的是主包 `jikuai` 的版本（当前基线 v0.6.0，随发布同步升级）。

## 环境变量

| 变量 | 作用 |
|------|------|
| `PYTHONPATH` | 指到 `src`，即可免安装运行 |
| `JIKUAI_PATH` | 追加 `.jk` 模块搜索目录（搜索顺序：当前文件目录 → `stdlib/` → `JIKUAI_PATH`）|
| `JIKUAI_DIAGNOSTICS=off` | 关闭警告/提示类诊断输出（错误仍然报）|

## 退出码约定

| 退出码 | 含义 |
|--------|------|
| 0 | 正常结束。**警告类诊断（如 `JK-W1001`）走 stderr，不影响退出码** |
| 1 | 语法错误 / 运行期错误 / 文件找不到 / 编码不是 UTF-8 |

这条约定是本教程 CI 的基础：所有标了 `run: true` 的片段都断言退出码 0。

## 先跑一个现成示例

仓库自带示例，挑一个跑：

```bash
PYTHONPATH=src python -m jikuai examples/hello.jk
PYTHONPATH=src python -m jikuai examples/pipeline.jk
PYTHONPATH=src python -m jikuai examples/scenarios/财务报表/main.jk
```

场景示例（`examples/scenarios/<名字>/`）每个都带 `README.md` 与
`expected.txt` 快照，可以对着比对输出。

## 验证安装成功

把下面这段存成 `试试.jk` 再 `jk 试试.jk`，能看到三行输出就说明装好了：

<!-- run: true -->
<!-- expect: 你好，极快！ -->
<!-- expect: 8 -->
<!-- expect: ￥100.50 -->
```jikuai
打印 "你好，极快！"。
打印 加 3 5。
打印 ￥100.50。
```
