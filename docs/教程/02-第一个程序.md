# 02 · 第一个程序

> 最小闭环第 2 步。这一章讲清语句、变量、算术、打印四件事。

## Hello, 极快

<!-- run: true -->
<!-- expect: 你好，极快！ -->
```jikuai
打印 "你好，极快！"。
```

三个要点：

1. `打印` 是**内建动词**，后面直接跟参数，不需要括号
2. 字符串用**半角双引号** `"..."` 包起来
3. 语句用**中文句号 `。`** 结束 —— 不是英文句点 `.`

## 语句与注释

| 符号 | 作用 |
|------|------|
| `。` | 语句结束（**必须**）|
| `：` | 开启一个块（`如果`/`遍历`/`函数`/`类` 之后）|
| `。` 单独一行 | 关闭一个块 |
| `--` | 单行注释，到行尾 |

<!-- run: true -->
<!-- expect: 1 -->
```jikuai
-- 这是注释，不会被执行
打印 1。   -- 行尾注释也可以
```

## 变量：名字必须以百家姓开头

这是极快最有辨识度的规则：**变量名的第一个字必须是百家姓**
（赵、钱、孙、李、周、吴、郑、王、冯、陈、褚、卫……）。

<!-- run: true -->
<!-- expect: 42 -->
```jikuai
定义 赵数 = 42。
打印 赵数。
```

好处是「一眼分清自定义名字和语言内建名字」：看到 `赵`/`李`/`王` 开头就知道是变量，
看到 `打印`/`求和`/`长度` 就知道是内建动词。

合法：

```jikuai
定义 赵金额 = 100。
定义 李姓名 = "小张"。
定义 王计数器 = 0。
定义 周i = 1。
```

**不合法**（下面这段是反例，不会执行）：

```
定义 数量 = 10。      -- 「数」不是百家姓 → 报错
定义 myVar = 10。     -- 英文名 → 报错
定义 x = 1。          -- 单字母 → 报错
```

`定义` 两侧的空格可有可无，下面两种写法等价：

<!-- run: true -->
<!-- expect: 7 -->
<!-- expect: 7 -->
```jikuai
定义 赵甲 = 7。
定义赵乙=7。
打印 赵甲。
打印 赵乙。
```

再次赋值也用 `定义`：

<!-- run: true -->
<!-- expect: 1 -->
<!-- expect: 2 -->
```jikuai
定义 赵计 = 1。
打印 赵计。
定义 赵计 = 赵计 加 1。
打印 赵计。
```

## 算术：中缀与前缀两种写法

极快的算术动词是 `加` `减` `乘` `除`，**前缀和中缀两种写法都成立**：

<!-- run: true -->
<!-- expect: 8 -->
```jikuai
打印 加 3 5。
```

<!-- run: true -->
<!-- expect: 8 -->
```jikuai
打印 3 加 5。
```

小数照常：

<!-- run: true -->
<!-- expect: 50.0 -->
```jikuai
定义 李价 = 12.5。
打印 李价 乘 4。
```

嵌套调用用括号分组：

<!-- run: true -->
<!-- expect: 20 -->
```jikuai
打印 (加 3 5) 乘 (减 4 1) 减 4。
```

> **注意**：`打印` 是**变参动词**，会尽量吞掉后面的参数。想让它只打印一个
> 复合表达式的结果，给表达式**加括号**最稳妥。

## 打印与拼接

`打印` 一次可以吃多个参数（变参），也可以先用 `拼接` 拼成一个字符串：

<!-- run: true -->
<!-- expect: 你好，小张！ -->
```jikuai
定义 赵名 = "小张"。
打印 拼接 "你好，" 赵名 "！"。
```

数字要拼进字符串时，先 `转字符串`：

<!-- run: true -->
<!-- expect: 一共 3 件 -->
```jikuai
定义 赵件数 = 3。
打印 拼接 "一共 " (转字符串 赵件数) " 件"。
```

## 条件分支

块用 `：` 开启、单独一行的 `。` 关闭：

<!-- run: true -->
<!-- expect: 及格 -->
```jikuai
定义 赵分 = 88。
如果 赵分 大于等于 60 那么：
  打印 "及格"。
否则：
  打印 "不及格"。
。
```

比较动词：`等于` `不等于` `大于` `小于` `大于等于` `小于等于`。

## 循环

<!-- run: true -->
<!-- expect: 1 -->
<!-- expect: 2 -->
<!-- expect: 3 -->
```jikuai
遍历 赵i 于 范围 1 4：
  打印 赵i。
。
```

`范围 起 止` 是**左闭右开**的，`范围 1 4` 是 1、2、3。

遍历列表：

<!-- run: true -->
<!-- expect: 甲 -->
<!-- expect: 乙 -->
<!-- expect: 丙 -->
```jikuai
定义 赵表 = 列 "甲" "乙" "丙"。
遍历 赵项 于 赵表：
  打印 赵项。
。
```

## 列表与下标

`列` 后面直接跟元素，元素之间空格分隔（**不用逗号** —— 逗号是管道符）：

<!-- run: true -->
<!-- expect: 乙 -->
<!-- expect: 3 -->
<!-- expect: [1, 2, 3] -->
```jikuai
定义 赵表 = 列 "甲" "乙" "丙"。
打印 赵表[1]。
打印 长度 赵表。
打印 排序 (列 3 1 2)。
```

## 函数

<!-- run: true -->
<!-- expect: 42 -->
```jikuai
函数 赵翻倍 接收 赵n：
  返回 赵n 乘 2。
。
打印 赵翻倍(21)。
```

注意：**调用用户函数要带括号**，`赵翻倍(21)`。免括号（元数驱动）只适用于内建动词。

## 异常

<!-- run: true -->
<!-- expect: 捕获到错误 -->

尝试：
  打印 除 1 0。
捕获 赵错：

## 类

<!-- run: true -->
<!-- expect: 我是小张 -->
```jikuai
类 学生：
  构造 接收 赵名：
    自身.名字=赵名。
  。
  方法 问好：
    打印 拼接 "我是" 自身.名字。
  。
。
定义 赵人 = 新建学生("小张")。
赵人.问好。
```

## 小结：一个完整的小程序

<!-- run: true -->
<!-- expect: 姓名：小张 -->
<!-- expect: 三科总分：258 -->
<!-- expect: 平均分：86.0 -->
<!-- expect: 评定：优秀 -->
```jikuai
定义 赵姓名 = "小张"。
定义 赵成绩 = 列 85 92 81。

打印 拼接 "姓名：" 赵姓名。
定义 赵总分 = 求和 赵成绩。
打印 拼接 "三科总分：" (转字符串 赵总分)。
定义 赵均分 = 平均 赵成绩。
打印 拼接 "平均分：" (转字符串 赵均分)。

如果 赵均分 大于等于 85 那么：
  打印 "评定：优秀"。
否则：
  打印 "评定：良好"。
。
```
