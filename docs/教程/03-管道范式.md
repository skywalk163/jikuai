# 03 · 管道范式

> 极快最有表现力的武器：逗号管道。数据从左到右流过一串操作，一行写完。

## 基本形状

```
列表，副词 动词 参数，副词 动词 参数，…。
```

三大副词：

| 副词 | 功能 | 类比 |
|------|------|------|
| `皆` | 映射（map）：对每个元素调用动词 | `[f(x) for x in lst]` |
| `只` | 过滤（filter）：只保留动词返回真的元素 | `[x for x in lst if f(x)]` |
| `归` | 归约（reduce）：从初值开始累积计算 | `reduce(f, lst, init)` |

## 皆（映射）

<!-- run: true -->
<!-- expect: [2, 4, 6, 8, 10] -->
```jikuai
定义 赵表 = 列 1 2 3 4 5。
打印 (赵表，皆乘2)。
```

<!-- run: true -->
<!-- expect: [11, 12, 13, 14, 15] -->
```jikuai
打印 (列 1 2 3 4 5，皆加10)。
```

## 只（过滤）

<!-- run: true -->
<!-- expect: [3, 4, 5] -->
```jikuai
打印 (列 1 2 3 4 5，只大于2)。
```

<!-- run: true -->
<!-- expect: [1, 2] -->
```jikuai
打印 (列 1 2 3 4 5，只小于3)。
```

## 归（归约）

<!-- run: true -->
<!-- expect: 15 -->
```jikuai
打印 (列 1 2 3 4 5，归加0)。
```

`归加0` 是求和：从初值 0 开始，每次 `加(累积, 元素)`。
`归乘1` 是累乘：从初值 1 开始，每次 `乘(累积, 元素)`。

<!-- run: true -->
<!-- expect: 120 -->
```jikuai
打印 (列 1 2 3 4 5，归乘1)。
```

## 链式：管道可以随意串联

<!-- run: true -->
<!-- expect: 24 -->
```jikuai
打印 (列 1 2 3 4 5，皆乘2，只大于4，归加0)。
```

读法：列表 → 每个乘 2 → 只留大于 4 的 → 求和。即 `[6, 8, 10]` 的和 = 24。

## ⚠️ 最重要的坑：副词只识别内建动词

这条必须记牢：**`皆` / `只` / `归` 后面只能接内建动词**。
接用户函数会**原值透传**（不报错，但也没效果），并触发 `JK-W1001` 警告。

下面是**反例**（不带 run 标注，不会执行）：

```
函数 赵翻倍 接收 赵n：
  返回 赵n 乘 2。
。
定义 赵表 = 列 1 2 3。
打印 (赵表，皆赵翻倍)。
-- 输出 [1, 2, 3]（原值透传），stderr 会有 JK-W1001
```

**正确做法**：用 `遍历` 手动调用用户函数，或改用内建动词能表达的形式
（翻倍就写 `皆乘2`）。

## 副词参数可以是变量

<!-- run: true -->
<!-- expect: [6, 7, 8] -->
```jikuai
定义 赵阈值 = 5。
打印 (列 1 2 3 4 5 6 7 8，只大于赵阈值)。
```

## 打印管道结果的注意事项

`打印` 是变参动词，会贪婪吞参数。想让它只打印管道结果，**加括号**：

```
打印 (赵表，皆乘2)。   -- ✅
打印 赵表，皆乘2。      -- ❌ 打印先吃掉 赵表，管道作用在返回值(空)上
```

最佳实践：先 `定义` 到变量再 `打印`。

<!-- run: true -->
<!-- expect: [2, 4, 6] -->
```jikuai
定义 赵表 = 列 1 2 3。
定义 赵结果 = 赵表，皆乘2。
打印 赵结果。
```
