# 04 · 中国特色能力

> 人民币、农历、中文数字、大写金额、身份证与手机号校验 —— 全部内建，不需要 `导入`。

## 人民币字面量

<!-- run: true -->
<!-- expect: ￥100.50 -->
```jikuai
打印 ￥100.50。
```

`￥` 字面量按**分精确存储**（内部是 Python `Decimal`），不是浮点数，
所以不会出现 `0.1 + 0.2 != 0.3` 这类误差。求和保持精确：

<!-- run: true -->
<!-- expect: ￥148.40 -->
```jikuai
定义 赵单 = 列 ￥19.90 ￥8.50 ￥120.00。
打印 求和 赵单。
```

人民币也是管道里的一等公民：

<!-- run: true -->
<!-- expect: [￥120.00] -->
<!-- expect: ￥120.00 -->
```jikuai
定义 赵单 = 列 ￥19.90 ￥8.50 ￥120.00。
定义 赵大额 = 赵单，只大于 ￥100.00。
打印 赵大额。
打印 求和 赵大额。
```

## 大写金额

开票、合同、报销单都要的中文大写：

<!-- run: true -->
<!-- expect: 壹仟贰佰叁拾肆元伍角陆分 -->
```jikuai
打印 大写金额 ￥1234.56。
```

整数金额会补「整」字：

<!-- run: true -->
<!-- expect: 壹佰元整 -->
```jikuai
打印 大写金额 ￥100.00。
```

<!-- run: true -->
<!-- expect: 二千零二十六 -->
```jikuai
打印 汉字数字 2026。
```

也能作为管道段批量转换：

<!-- run: true -->


## 农历 / 干支 / 生肖

四个内建动词：

| 动词 | 元数 | 返回 |
|------|------|------|
| `干支纪年 年` | 1 | 天干地支，如 `丙午` |
| `生肖 年` | 1 | 生肖，如 `马` |
| `农历完整日期 年 月 日` | 3 | 中文完整农历串 |
| `公历转农历 年 月 日` | 3 | `[农历年, 农历月, 农历日, 是否闰月]` |

<!-- run: true -->
<!-- expect: 丙午 -->
<!-- expect: 马 -->
<!-- expect: 丙午(马)年 八月十八 -->
<!-- expect: [2026, 8, 18, False] -->
```jikuai
打印 干支纪年 2026。
打印 生肖 2026。
打印 农历完整日期 2026 8 8。
打印 公历转农历 2026 8 8。
```

`生肖` 和 `干支纪年` 都是内建动词，可以直接进管道：

<!-- run: true -->
<!-- expect: ['龙', '蛇', '马', '羊', '猴'] -->
```jikuai
打印 (列 2024 2025 2026 2027 2028，皆生肖)。
```

> **有效范围：公历 1900 - 2100**。超出会静默给出错误结果（低于下界）
> 或抛运行期错误（高于上界）。另外 `干支纪年` / `生肖` 不做春节边界修正，
> 详见第 08 章。

## 国情校验

| 动词 | 校验对象 |
|------|---------|
| `校验身份证` | 18 位身份证形态与校验位 |
| `校验手机号` | 长度与号段首两位 |
| `校验银行卡` | Luhn 校验 |
| `校验车牌` | 民用车牌形态 |
| `校验社会信用代码` | 统一社会信用代码 |

<!-- run: true -->
<!-- expect: 真 -->
```jikuai
打印 校验身份证("11010519491231002X")。
```

<!-- run: true -->
<!-- expect: 真 -->
```jikuai
打印 校验手机号("13800138000")。
```

这些名字同时也由 `校验` 模块导出，两种写法等价：

<!-- run: true -->
<!-- expect: 真 -->
```jikuai
从 校验 导入 校验手机号。
打印 校验手机号("13800138000")。
```

## 综合：一张报销单

<!-- run: true -->
<!-- expect: 小计：￥204.30 -->
<!-- expect: 税额：￥12.26 -->
<!-- expect: 合计：￥216.56 -->
<!-- expect: 大写：贰佰壹拾陆元伍角陆分 -->
```jikuai
定义 赵明细 = 列 ￥58.00 ￥6.30 ￥140.00。
定义 赵小计 = 求和 赵明细。
定义 赵税 = 赵小计 乘 0.06。
定义 赵合计 = 赵小计 加 赵税。
打印 拼接 "小计：" (转字符串 赵小计)。
打印 拼接 "税额：" (转字符串 赵税)。
打印 拼接 "合计：" (转字符串 赵合计)。
打印 拼接 "大写：" (大写金额 赵合计)。
```
