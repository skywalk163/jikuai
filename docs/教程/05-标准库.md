
## 正则

<!-- run: true -->
<!-- expect: 真 -->
```jikuai
导入 正则。
打印 正则.匹配("[0-9]+", "199")。
```

<!-- run: true -->
<!-- expect: 你好，中国！ -->
```jikuai
导入 正则。
打印 正则.替代("世界", "中国", "你好，世界！")。
```

> 注意：导出名叫 `替代`（不是 `替换`），因为 `替换` 是内建动词会被分词器识别成 VERB token。
