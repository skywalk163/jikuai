# 07 · 开发工具链

> 最小闭环第 4 步。VS Code 扩展装上，写极快代码就有颜色 + 实时报错。

## VS Code 扩展

### 安装

1. 安装 LSP Server：`pip install -e lsp/`
2. 安装扩展：`code --install-extension editors/vscode/jikuai-vscode-0.6.0.vsix`
3. 新建 `.jk` 文件，开始编写

### 能力

| 功能 | 状态 |
|------|------|
| 语法高亮（TextMate grammar） | ✅ 不依赖 LSP |
| 实时诊断（publishDiagnostics） | ✅ 经 LSP |
| 自动补全（`.` / `，` 触发） | ✅ 经 LSP |
| Hover 悬浮提示 | ✅ 经 LSP |
| 断点调试 | ✅ 经 DAP（M9-2） |

> 语法高亮**不依赖 LSP**。即使 LSP 未安装，高亮仍可用；
> 诊断 / 补全 / hover 会自动降级关闭。

### 配置

在 `settings.json` 中：

```json
{
  "极快.pythonPath": "python",
  "极快.lsp.enabled": true
}
```

### LSP Server

```bash
python -m jikuai_lsp   # 走 stdio，阻塞等待客户端
```

## 包管理（M8）

依赖分发用内置的 `jk 包` 子命令族，命令与文件全部中文化。

```bash
jk 包 初始化 我的应用         # 生成 包.json
jk 包 添加 甲 --路径 ../甲    # 添加本地目录依赖
jk 包 装                     # 在新机器上按清单还原
jk 包 列表
```

- 清单：`包.json`（提交进版本库）
- 锁文件：`包.锁`（提交进版本库，字节稳定，同输入产同 diff）
- 安装目录：`极快_包/`（写进 .gitignore，由锁文件完整还原）
- 三种依赖来源：`路径` / `仓库`(git) / `注册表`（后者暂未上线）

`导入 甲` 自动从 `极快_包/甲/` 加载。完整语义、版本约束语法、
安全边界见 [docs/包管理.md](../包管理.md)。
