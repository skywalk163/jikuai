# 08 · 已知限制

> 踩坑清单。遇到诡异行为先来这里查。

## 1. 副词只识别内建动词（JK-W1001）

`皆` / `只` / `归` 后面只能接**内建动词**。接用户函数或模块函数会**原值透传**
（不报错，但没效果），并在 stderr 输出 `JK-W1001` 警告。

正确做法：用 `遍历` 手动调用用户函数。

## 2. `.jk` 字符串里反斜杠会被吞

转义表只认 `\n` `\t` `\\` `\"` `\'`，**未知转义会丢掉反斜杠**。

```
"\d"   → 实际得到 "d"     ❌
"\\d"  → 实际得到 "\d"    ✅
```

写正则时推荐用字符类规避：`[0-9]` 代替 `\d`，`[一-鿿]` 代替 `\汉`。

## 3. `替代` vs `替换`

`正则` 模块的全局替换 API 导出名叫 **`替代`**（不是 `替换`）。
原因：`替换` 被分词器识别为内建 VERB token，做标识符名会冲突。

## 4. pybridge 非沙箱

Python 互操作的黑名单拦截不是沙箱。不要用于执行不受信任的代码。
详见第 06 章与 `docs/安全边界.md`。

## 5. `标识符(` 会被解析成函数调用

在语句中出现 `标识符(表达式)` 时，解析器认为是**函数调用**。
如果你想让括号只做分组，中间不能紧跟标识符：

```
定义 赵片 = 子串 赵文 钱i (钱i加4)。   -- ❌ 报「不可调用的对象」
定义 钱止 = 钱i加4。                    -- ✅ 先算好再传
定义 赵片 = 子串 赵文 钱i 钱止。
```

## 6. 农历数据有效范围 1900-2100

`公历转农历` / `农历完整日期` 等动词只在此区间内可信。超出时可能静默给出错误结果或抛运行期错误。

## 7. `干支纪年` / `生肖` 不做农历年首修正

按公历年份取模，不考虑春节边界。公历 1 月到春节之间的日期，干支/生肖按公历年份计算。

## 8. 分词词典是常用词子集（565 条）

未收录的词按单字兜底切。四字成语不在词典里（会被切成四个单字）。
