# 极快标准库参考（v0.5.0 · M4）

`stdlib/` 位于**仓库根目录**（不是 `src/` 下）。加载器 `module_loader._search_paths()`
以 `os.path.join(here, "..", "..", "stdlib")` 从 `src/jikuai/` 上溯两级定位，
搜索优先级为：当前文件目录 → `stdlib/` → `JIKUAI_PATH` 环境变量。

## 契约总则

### 导出机制

`.jk` 模块的公共 API 由源码中的**运行期 `导出` 语句**声明，没有 `__导出__`
这类魔法变量（ADR-16 决议 B）。

- `evaluator._current_exports` 在模块体执行期间收集导出名
- `module_loader.load()` 用收集结果构造 `ModuleValue(name, env, exports, ev)`
- `ModuleValue.get(attr)` 对未导出的名字直接抛错

### 模块形态

三种形态并存：

- 纯 `.jk` 模块：如 `工具`
- 纯 `.py` 模块：如 `历法`，不参与 `导入` 的模块名解析，只经内建动词暴露
- 混合模块：`X.jk` + 同名 `X.py`，如 `校验` / `简繁` / `排版`

混合模块语义（ADR-16 §3.3）：`.jk` 是**唯一对外门面**，`.py` 是内部实现且
不参与模块名解析。加载 `X.jk` 时，加载器以 `importlib.util.spec_from_file_location`
隔离导入同名 `.py`（**不污染 `sys.path`**），并把它自身定义的公共可调用对象
注入模块环境。注入受三重约束：跳过下划线开头的名字、遵守 `.py` 的 `__all__`
声明、只注入 `__module__` 与该 `.py` 相符的对象（不透传 import 进来的第三方符号）。
注入不等于导出——未写进 `导出` 语句的注入名依旧被 `ModuleValue.get()` 拦截。

### 错误码

模块系统的两条错误路径携带稳定错误码（消息前缀形式）：

- `JK-E5001` 找不到模块，消息含模块名，形如 `[JK-E5001] 找不到模块：不存在的模块`
- `JK-E5002` 模块未导出该名字，形如 `[JK-E5002] 模块 工具 未导出：不存在的符号`

### 内建动词 fallback（有意设计，非契约漏洞）

`ModuleValue.get(attr)` 在模块环境里找不到 `attr` 时，会回落到
`evaluator.verbs` 查内建动词。这是为薄封装模块服务的：`校验.jk` 只有一行
`导出` 语句、没有任何函数定义，它导出的名字全部经此路径解析到内建动词。

副作用是：一个名字只要同时出现在 `导出` 列表和内建动词表里，就能被访问，
即使模块本身没定义它。使用者不应依赖这一点来「借道」访问内建动词——请直接
在顶层调用动词。

### 契约门禁 G10

`scripts/check_stdlib_contract.py` 静态比对「`stdlib/*.jk` 的 `导出` 语句」与
「本文档各模块的公共符号清单」，不一致即以退出码 1 失败。因此**本文档的公共
符号清单是契约的一部分**，改动导出必须同步改文档。

### 公共符号

- 转繁体
- 转简体

### 示例

```
导入 简繁。

打印 简繁.转繁体("中国计算机学会发布国家标准")。
-- 中國計算機學會發布國家標準

打印 简繁.转简体("中國計算機學會發佈國家標準")。
-- 中国计算机学会发布国家标准

打印 简繁.转繁体("Hello, World 123!")。
-- Hello, World 123!    纯 ASCII 输入原样返回
```

### 一简对多繁的选定口径

逐字映射必须为每个歧义字选定唯一繁体。下列为本实现的固定口径，
「未覆盖」列出的繁体字**不会**由 `转繁体` 产出，但 `转简体` 仍能把它还原：

- 发 → 發，取「發生」义；「頭髮」的髮不覆盖
- 后 → 後，取「後面」义；「皇后」的后不覆盖
- 干 → 幹，取「幹部」义；「乾燥」的乾、「干戈」的干不覆盖
- 台 → 臺，取「舞臺」义；「檯燈」的檯、「颱風」的颱不覆盖
- 里 → 裡，取「裡面」义；「公里」的里不覆盖
- 复 → 復，取「恢復」义；「複雜」的複不覆盖
- 钟 → 鐘，取「時鐘」义；姓氏鍾不覆盖
- 划 → 劃，取「計劃」义；「划船」的划不覆盖
- 丑 → 醜，取「醜陋」义；地支丑不覆盖
- 脏 → 臟，取「內臟」义；「髒亂」的髒不覆盖

上述口径以 `简繁.py` 的 `AMBIGUOUS_CHOICES` 为机器可读单一事实源，
`ambiguous_choices()` 可在运行期取回，测试据此断言，避免文档与实现漂移。

### 已知限制

- 逐字映射，无分词：`发型` 会转成 `發型` 而非 `髮型`
- 对照表是常用字集合而非全量 Unicode 映射，冷僻字原样透传
- 只处理字形，不做繁简地区词汇差异转换（如 软件/軟體、鼠标/滑鼠）
- 往返转换只对表内覆盖的字符成立；歧义字往返后会落到「选定」那一支

## 模块：排版

中文排版格式化。混合模块：门面 `排版.jk`，实现 `排版.py`。
主 API 是 `规范化文本`，另导出两个细粒度 API 便于单独使用。

### 公共符号

- 规范化文本
- 插入间距
- 规范标点

### 规则口径

R1 中西文间距（`插入间距`）

- 表意文字与半角英文字母/数字相邻时插入一个半角空格
- 两侧都处理：中文在前或半角在前都插
- 已有空格不重复插入
- 表意文字的判定范围是 U+3400–U+4DBF、U+4E00–U+9FFF、U+F900–U+FAFF、
  U+20000–U+2A6DF，**不含标点、不含全角字母数字**

R2 标点规范化（`规范标点`），三步固定顺序

- R2a 折叠：连续 2 个以上半角空格折叠为 1 个
- R2b 转全角：紧跟在表意文字之后的半角 `,` `.` `!` `?` `;` `:` 转为 `，` `。` `！` `？` `；` `：`
- R2c 收紧：全角标点两侧紧邻的半角空格一律删除

R2 有意收窄，以下情形**不处理**：

- ASCII 括号 `(` `)` 与引号，不做全角化
- 不紧跟表意文字的半角标点，如 `3.14` 的小数点、`a, b` 的逗号，保持原样
- 首尾空白不裁剪，避免与调用方的模板拼接语义冲突

R3 幂等性（AC-M4-05-02，硬要求）

`规范化文本` 满足 `f(f(x)) == f(x)`。成立理由：

- `规范化文本` 固定为「先 `规范标点`、后 `插入间距`」
- `插入间距` 只在「无空格的表意文字↔半角字母数字」边界插空格，插入后该边界
  不再满足条件，第二遍无操作
- R2a/R2b/R2c 各自幂等
- `插入间距` 插入的空格两侧一个是表意文字、一个是半角字母数字，都不是全角
  标点，所以不会破坏 R2c 的不变量；同时它不移动字符，不会造出新的
  「表意文字 + 半角标点」组合去破坏 R2b 的不变量

### 示例

```
导入 排版。

定义 赵原稿 = "极快JiKuai是第1个适合中国国情的中文编程语言,值得一试!"。
定义 赵成稿 = 排版.规范化文本(赵原稿)。
打印 赵成稿。
-- 极快 JiKuai 是第 1 个适合中国国情的中文编程语言，值得一试！

打印 排版.规范化文本(赵成稿)。   -- 幂等，与上一行完全相同

打印 排版.规范标点("中文标点,句号. 英文小数 3.14 不动")。
-- 中文标点，句号。英文小数 3.14 不动
```

### 已知限制

- 不处理全角字母数字（Ａ１）与中文之间的间距
- 不处理换行/制表符相关的排版，只处理半角空格
- R2b 只看紧邻的前一个字符，`中文 ,` 中间有空格时不转全角
- 不做中文标点的类型推断（无法判断 `"` 该转成 `「` 还是 `」`）
- `punctuation_rules()` 返回的规则描述供文档与测试引用，不是稳定公共 API

## 模块：正则

中文正则表达式。混合模块：门面 `正则.jk`，实现 `正则.py`。底层引擎为 Python
标准库 `re`，只做薄封装。无命中不报错：`搜索` 返回空、`匹配` 返回假、`替换`
原样返回文本。

### 公共符号

- 匹配
- 搜索
- 替代
- 编译

### 支持的语法子集（契约）

明确声明**仅支持**下列子集，其余交由底层 `re` 决定：

- 字面量：普通字符按原样匹配
- 字符类 `[]`：含中文范围，如 `[一-十]`、`[\u4e00-\u9fff]`
- 量词：`*` `+` `?` `{n}` `{n,}` `{n,m}`
- 分组：`()`
- 或：`|`

中文别名（编译前预处理，纯字符串替换）：

- `\汉` 等价 `[\u4e00-\u9fff]`，匹配任意常用汉字

**不支持**（超出子集，由 `re` 底层报错并包装成清晰的中文错误消息）：

- 反向引用 `\1`
- 断言（前视/后视 `(?=...)` `(?<=...)` 等）
- 命名分组等其余 `re` 高级语法（可用但不在契约保证范围内）

### 写模式时的反斜杠陷阱（必读）

`.jk` 字符串字面量的转义表只认 `\n` `\t` `\\` `\"` `\'`，**未知转义会丢掉
反斜杠**（`lexer._read_string`：`esc_map.get(esc, esc)`）。因此：

- `"\d+"` 在 `.jk` 里等于 `"d+"`，会按字面量 `d` 匹配，不是「数字」
- 要表达 `\d`，`.jk` 源码里必须写 `"\\d+"`
- 同理中文别名要写 `"\\汉+"`

**推荐写法**：直接用字符类完全绕开反斜杠——

- 数字用 `[0-9]` 代替 `\d`
- 汉字用 `[一-鿿]` 代替 `\汉`

这条是语言级行为，不是本模块的缺陷；本模块只负责在文档里把它讲清楚。

### API 口径

- `匹配(模式, 文本) -> 布尔`：整串匹配（等价 `re.fullmatch`）。文本为空返回假
- `搜索(模式, 文本) -> 结果 或 空`：找到首个匹配返回字典 `{文本, 起始, 结束}`，
  区间为半开区间（`文本[起始:结束]` 即匹配串）；未命中返回空
- `替代(模式, 新文本, 原文) -> 字符串`：替换全部匹配；无匹配返回原文
- `编译(模式) -> 编译对象`：返回字典 `{源, _编译对象}`，可作为 `模式` 参数
  重复传给上述三个函数，避免重复编译

### 示例

```
导入 正则。

打印 正则.匹配("[一-十]+", "一二三")。      -- 真
打印 正则.搜索("[一-鿿]+", "abc中文def")。   -- {文本: 中文, 起始: 3, 结束: 5}
打印 正则.搜索("\\汉+", "abc中文def")。      -- 同上（反斜杠写两遍）
打印 正则.搜索("[0-9]+", "价格199元")。      -- {文本: 199, 起始: 2, 结束: 5}
打印 正则.替代("世界", "中国", "你好，世界！")。  -- 你好，中国！
```

### 已知限制

- 语法子集之外的写法能力取决于 Python `re`，不在本模块契约保证内
- `搜索` 只返回首个匹配，不做全局 findall
- `编译` 返回的字典含内部键 `_编译对象`，属实现细节，不应被外部直接依赖

## 模块：成语

中文成语断言与释义。混合模块：门面 `成语.jk`，实现 `成语.py`。

内置常用四字成语 **313 条**（版本 `v0.6.0-300`，规模口径以 `library_size()`
为单一事实源），每条含中文释义。**零依赖**：成语库以字面量内置在 `成语.py`，
不读外部文件、不依赖任何第三方 pip 包。查找基于 `dict` 与 `frozenset`，为
O(1) 哈希查表。本模块调用**只读、无副作用、天然幂等**。

只覆盖四字成语，不含谚语、歇后语、俗语。

### 公共符号

- 是成语
- 成语释义

### API 口径

- `是成语(词语) -> 布尔`：词语是否在库内。非字符串/空输入返回假，不报错
- `成语释义(词语) -> 字符串 或 空`：返回释义；不在库内返回空

### 示例

```
导入 成语。

打印 成语.是成语("胸有成竹")。       -- 真
打印 成语.是成语("随便一个词")。     -- 假
打印 成语.成语释义("胸有成竹")。     -- 做事之前已有全面的考虑和打算
```

### 已知限制

- 只是常用成语子集（313 条），冷僻成语可能不在库内 → 返回假/空
- 只做精确整词匹配，不做成语纠错、近义检索或从句子中抽取成语
- 释义为简明白话，非权威辞书释义

## 模块：分词

中文分词。混合模块：门面 `分词.jk`，实现 `分词.py`。

词典 **58713 条**（单字词一律不入库，词长 2-8 字），策略为**正向最大匹配**
（Forward Maximum Matching, FMM）。词典为模块级不可变 `frozenset`，运行期
只读；分词过程零写入、无 `global`、无缓存，故**幂等且无全域副作用**
（G12 · AC-M5-07-01/02/03）。

词典是**外部数据文件** `stdlib/分词词典.txt`（随包分发），由
`tools/dict/重生成词典.py` 从 jieba `dict.txt` 通用底座（MIT）+ 极快自有 565 条
必留种子 + THUOCL 财经/法律词表（MIT）合并生成，**仍是零第三方运行时依赖**。
来源与授权见 `stdlib/分词词典来源.md`，校验和见 `stdlib/分词词典.元信息.json`，
设计决策见 `docs/ADR-38-中文分词词典.md`。词典文件缺失时**导入即抛异常，
不静默降级**。

### 公共符号

- 分词

### API 口径

- `分词(文本) -> 列表`：把文本切分成词序列，每次返回**新建**的列表

### 切分口径（兜底策略）

主路径命中词典的长词优先；未命中时按下列兜底策略逐字符处理：

- B1 空白字符（空格 / 制表 / 换行 / 全角空格）：作分隔符，**不产出词项**
- B2 半角字母数字：连续的 `[0-9A-Za-z]` 作为**一个**词项整体产出
  （如 `JiKuai2026` 整体成词）
- B3 其余字符（词典外汉字、标点、符号）：**单字成词**，逐个产出

因此：

- 空字符串 → 返回空列表 `[]`
- 纯标点（如 `。。，`）→ 每个标点各占一项 `["。", "。", "，"]`

### 示例

```
导入 分词。

打印 分词.分词("中国程序员的中文编程语言")。
```

### 已知限制

- 正向最大匹配无法消解切分歧义（如「北京大学」若两词都在库则取最长）

- 词条最长 8 字（性能决策，见 ADR-38 §4）；更长的短语不会被整体切出
