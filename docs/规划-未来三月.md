## 判断:现在最该做什么

v0.24.0 把「**能不能发**」解决了。接下来三个月的主线是把「发出去的东西**别再带病、且真有人能用**」补齐。按价值和风险排序:

1. **CI/CD 是头号真空**(v0.25 主轴)。现在零自动化门禁,全靠人肉在本机跑。刚上公网 PyPI,这个洞必须先堵。它同时解锁两笔老挂账(覆盖率线上化 W94、macOS CI W95)。
2. **生态冷启动**(v0.26 主轴)。包在 PyPI 上了,但 README 面向开发者、没有「装完 30 秒跑通」的使用者引导。发布的价值只有被人用才兑现——但「生态」很模糊,**进场前必须先 brainstorming 澄清到底做什么**。
3. **反馈驱动 + 清账**(v0.27)。第三个月刻意留白:按前两月带来的真实反馈决定,叠加几个确定的清账项。现在就把它定死违反项目自己「等具名需求」的纪律。

## v0.25(第 1 月)· CI/CD 与发布自动化

**主轴**:把现有全套门禁搬上持续集成,并让发版走自动化而非人肉 twine。

**先决策(进场第一件事)**:CI 落在哪个平台?本机连 github 都反复 300s 超时(见 v0.24 教训),GitHub Actions 的可用性存疑。候选:GitHub Actions / Gitea Actions(自托管,`192.168.1.5`)/ GitCode。**这个拍板决定后面所有 YAML 往哪写**,不定不动手。

**里程碑草案**:
- **W121 · 门禁上 CI**:push/PR 触发 → 装依赖 → 全量 pytest + G10-G19 + G20(要真 build)+ `verify_wheel_e2e` 干净 venv 验收。跨 Linux/macOS/Windows 矩阵(顺带清 **v0.21 W95** macOS CI 挂账)。
- **W122 · 覆盖率线上化**:把 `scripts/coverage_baseline.py` 的两级阈值接进 CI 当门禁(清 **v0.21 W94**);此前它「全空转」(v0.22 教训:守卫绿≠守卫在守)。
- **W123 · 发版自动化**:tag `vX.Y.Z` 触发 → build 三包 → `twine check` → 发 PyPI。**强烈建议用 Trusted Publishing(OIDC),不再存 token**——比 `.env` 里的长效 token 安全一个量级。发布前强制过 G20 + e2e。
- **顺带清账**:yank 掉 PyPI 上的 `jikuai` 0.4.1(人工网页操作,CI 管不了 yank);把「无 CI」这个缺口本身从隐性变显性记进 BACKLOG。

**风险**:Trusted Publishing 要在 PyPI 后台配 GitHub 仓库绑定,若 CI 不落在 GitHub 则用不了,退回 token(存 CI secret,不存明文)。大端真机验证若想做,可在这一步加 QEMU s390x runner 跑那条 monkeypatch 用例的真机版(见 ADR-39 §7.1)。

## v0.26(第 2 月)· 生态冷启动与上手体验

**主轴**:让一个此前没听过极快的人,`pip install jikuai` 后能在几分钟内跑通一个真实中国式业务场景。

**进场必做**:先走 **brainstorming**。「生态冷启动」现在是个筐,要先澄清到底是(a)使用者文档、(b)首次运行引导、(c)错误信息打磨、(d)一个杀手级 demo、还是(e)对外宣发。不澄清就动手 = 造无需求的玩具(违反 W67 纪律)。

**候选方向(待 brainstorming 收敛,不全做)**:
- 面向**使用者**(非贡献者)的快速上手:README 顶部加「装完就跑」的三行,配一个 `个税/工资册/对账` 真场景。
- `jk` 裸跑(无参数)时的引导输出:提示 `jk 块 选`、`jk 包`、REPL 入口,而不是报错退出。
- 错误信息走查:挑几条最常撞见的诊断码,确认中文文案对使用者(非开发者)友好。
- examples/ 全量走查:确认每个 `.jk` 在**从 PyPI 装的干净环境**里能跑(而非仅 editable)。

**风险**:这一版最容易跑偏成「文档大扫除」。必须用「一个新用户实际卡在哪」当验收锚,不是「文档看起来全不全」。

## v0.27(第 3 月)· 反馈驱动 + 清账

**主轴现在不定**,按 v0.25/v0.26 产生的真实信号在进场时拍。三个候选源:

- **L3 块扩容**(BACKLOG §4):仅当冷启动带来**具名需求**才启动;否则继续顺延。启动须重跑 `generate_embeddings.py` 过 G12。
- **检索语义路线**(检索拒答缺口那条长期悬案):词面路线四轮已全证伪,语义路线要不要拍板一直没定。若有余量可立项调研,但必须按双集 + 分档负例纪律报数。
- **确定的清账**:文档债 §7(14 个无独立文件的 ADR 编号)、大端真机验证(若 v0.25 没顺带做)、`spec/plan 放 docs/superpowers/ 与仓库 ADR 惯例并行` 的收口决定。
