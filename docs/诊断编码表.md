---

## 编码规则

- 格式：`JK-{E|W}{段}{序}`，四位数字
  - `E` = 错误（severity "错误"）
  - `W` = 警告（severity "警告"）
- 段 = 千位数字，表示错误域
- 序 = 后三位，域内递增

**不可变契约**：码一经发布只增不改不复用。已分配的错误码即使对应功能废弃，也不得重新分配给其他含义。

## 0xxx · 词法

### JK-E0001 — 非法字符

- severity：错误
- 类别：词法错误（`ErrorCategory.LEXER`）
- 触发条件：分词器遇到无法识别为任何合法 token 的字符
- 消息模板：`非法字符：'{char}'`
- 对应 AC/US：基础词法保障
- 首次出现版本：v0.5.0

## 1xxx · 语法 / 解析

### JK-E1001 — 意外的文件结束

- severity：错误
- 类别：语法错误（`ErrorCategory.SYNTAX`）
- 触发条件：解析器在期望更多 token 时遇到 EOF（如未闭合的块、缺少结束标点）
- 消息模板：`意外的文件结束，期望 '{expected}'`
- 对应 AC/US：基础语法保障
- 首次出现版本：v0.5.0

### JK-W1001 — 副词后接非内建动词，按原值透传

- severity：警告
- 类别：语法错误（`ErrorCategory.SYNTAX`）
- 触发条件：副词（`皆`/`只`/`归`）后接的 token 不在 `keywords.VERB_ARITY` 表中，分词器将副词按原值透传为标识符
- 消息模板：`副词 '{adverb}' 后接的 '{next}' 不是内建动词，按原值透传`
- 对应 AC/US：ADR-06 X2 降级机制 T1
- 首次出现版本：v0.5.0

## 2xxx · 名称 / 作用域

### JK-E2001 — 未定义的名称

- severity：错误
- 类别：名称错误（`ErrorCategory.NAME`）
- 触发条件：求值器在当前作用域链中找不到标识符绑定
- 消息模板：`未定义的名称：'{name}'`
- 对应 AC/US：基础名称解析
- 首次出现版本：v0.5.0

### JK-E2002 — 未知的内建动词（含拼写建议）

- severity：错误
- 类别：名称错误（`ErrorCategory.NAME`）
- 触发条件：token 以动词语法使用但不在 `keywords.VERB_ARITY` 中，且 `spelling_suggestion` 或 `diagnostics/spelling.py` 找到近似候选
- 消息模板：`未知的内建动词：'{name}'`（suggestions 字段携带候选列表）
- 对应 AC/US：US-M4-02（拼写建议增强）
- 首次出现版本：v0.5.0

- 首次出现版本：v0.5.0

## 5xxx · 模块 / 导入

### JK-E5001 — 找不到模块

- severity：错误
- 类别：模块错误（`ErrorCategory.MODULE`）
- 触发条件：`module_loader.resolve()` 在搜索路径（当前文件目录 → `stdlib/` → `JIKUAI_PATH`）中找不到目标模块
- 消息模板：`找不到模块：{module_name}`
- 对应 AC/US：AC-M4-03-03（消息含模块名）
- 首次出现版本：v0.5.0
- 备注：该消息已存在于现有代码，本次仅补错误码（见基线校正偏差 D）

### JK-E5002 — 模块未导出该名字

- severity：错误
- 类别：模块错误（`ErrorCategory.MODULE`）
- 触发条件：`ModuleValue.get(attr)` 发现 `attr` 不在该模块的 `exports` 集合中
- 消息模板：`模块 {name} 未导出：{attr}`
- 对应 AC/US：AC-M4-03-01（未导出成员的错误消息）、ADR-16 stdlib 契约
- 首次出现版本：v0.5.0
- 备注：该消息已存在于现有 `ModuleValue.get()` 实现，本次补错误码（见基线校正偏差 C）

## 6xxx · 互操作

### JK-E6001 — 命中 pybridge 拒绝清单

- severity：错误
- 类别：互操作错误（`ErrorCategory.INTEROP`）
- 触发条件：通过 `蟒:` 桥接调用的函数/模块命中 `pybridge.DENY_LIST`（如 `os.system`/`subprocess.Popen`/`builtins.eval`/`builtins.exec`）
- 消息模板：`安全限制：'{target}' 在 pybridge 拒绝清单中`
- 对应 AC/US：ADR-21 pybridge 安全边界
- 首次出现版本：v0.5.0

### JK-W6001 — pybridge 非沙箱信任提示

- severity：警告
- 类别：互操作错误（`ErrorCategory.INTEROP`）
- 触发条件：首次通过 `蟒:` 桥接加载外部 Python 模块时，提示用户 pybridge 不提供完整沙箱隔离
- 消息模板：`pybridge 仅基于黑名单做安全缓解，不提供沙箱隔离。请确保所执行的 Python 代码来源可信`
- 对应 AC/US：ADR-21 安全声明
- 首次出现版本：v0.5.0
