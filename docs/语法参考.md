## 1 词法

### 1.1 标识符：百家姓开头

变量、函数、类、参数名的**第一个字必须是百家姓姓氏**。这不是风格约定，
而是分词的基础设施：极快允许无空格书写，靠「姓氏开头」在词法层把
用户名字与关键字/动词无歧义地分开。

```jikuai
定义 赵甲 = 1。      -- 合法
定义 李总收入 = 100。 -- 合法
定义 收入 = 100。     -- 非法：不以姓氏开头
```

- 单字姓表见 `src/jikuai/surnames.py` 的 `SINGLE_SURNAMES`（400+ 字）。
- 复姓（`司马` / `欧阳` / `诸葛` …）见 `COMPOUND_SURNAMES`。
- 与关键字冲突的姓氏字被剔除：`空 非 真 假 长 大 小 于` 不能作姓氏开头。
- 类名、方法名、字段名、模块名**不受**此限制（它们的位置本身无歧义）。

### 1.2 无空格书写

关键字与动词按**最长贪心匹配**切分，因此下面两行等价：

```jikuai
打印 加 1 2。
打印加1 2。
```

优先级链（`lexer._read_han`）：
`蟒:` 桥前缀 → 用户定义名白名单 → 最长关键字/动词 → 百家姓标识符
→ 中文数字字面量 → 一般标识符兜底。

### 1.3 标点：全角半角等价

| 语义 | 全角 | 半角 |
|---|---|---|
| 语句结束 | `。` | —（无半角等价） |
| 管道 | `，` `、` | `,` |
| 块起始 | `：` | `:` |
| 圆括号 | `（）` | `()` |
| 方括号 | `【】` | `[]` |
| 花括号 | `「」` | `{}` |

语句以 `。` 结束。块以 `：` 开启、以单独一行的 `。` 闭合。

### 1.4 注释

```jikuai
-- 双减号注释，到行尾
# 井号注释，到行尾
```

### 1.5 源文件

- 编码必须是 UTF-8（不接受其他编码，会直接报错）。
- 扩展名 `.jk`。

## 2 字面量

```jikuai
定义 赵整 = 42。            -- 整数
定义 赵负 = -7。
定义 赵小数 = 3.14。         -- 小数（float）
定义 赵中文数 = 一百二十三。   -- 中文数字字面量 → 123
定义 赵文 = "你好"。         -- 字符串（ASCII 引号）
定义 赵文2 = “你好”。        -- 字符串（中文引号）
定义 赵真 = 真。            -- 布尔真
定义 赵假 = 假。            -- 布尔假
定义 赵空 = 空。            -- 空值（nil）
定义 赵钱 = ￥99.90。        -- 人民币字面量
定义 赵表 = 【1, 2, 3】。     -- 列表
定义 赵典 = {"键": 值}。      -- 字典（M8 起）
```

### 2.1 人民币字面量 `￥`

`￥99.90` 不是浮点数，而是**独立的 RMB 类型**，内部以「分」为整数单位存储，
用 `Decimal` 精确量化（ROUND_HALF_UP，对齐中国会计惯例）。

```jikuai
打印 加 ￥19.99 ￥0.01。    -- ￥20.00，不会出现 20.000000000000004
```

- 人民币 × 人民币 → 类型错误（金额相乘无意义）。
- 人民币 × 数值 → 人民币。
- 跨界到 Python 时映射为 `Decimal`；反向需显式 `人民币()` 包装。

### 2.2 中文数字字面量

`一二三四五六七八九十百千万亿` 组合会被识别为整数：

```jikuai
打印 一百二十三。   -- 123
打印 两千零五。     -- 2005
```

## 3 表达式

### 3.1 动词调用与元数驱动免括号

内建动词有**固定元数**，因此可以省略括号，按元数吃掉后续表达式：

```jikuai
打印 加 1 2。          -- 加 是二元，吃 1 和 2
打印 加 加 1 2 3。      -- (1+2)+3 = 6
打印 加(1, 2)。         -- 括号形式也合法
```

元数表见 [§10](#10-内建动词表)。`-1` 表示变参（吃到语句/终止符为止）。

完整元数解析规则见 [`docs/元数解析规范.md`](元数解析规范.md)。

### 3.2 成员访问与索引

```jikuai
打印 赵对象.字段。
打印 赵对象.方法()。
打印 赵表【0】。
打印 赵典["键"]。
打印 赵典.键。         -- 字典也支持点访问
```

### 3.3 无中缀运算符

极快**没有** `+ - * /` 中缀运算符，一律用动词前缀：

```jikuai
打印 加 1 2。       -- 而不是 1 + 2
打印 大于 3 2。     -- 而不是 3 > 2
```

例外：赋值的 `=` 是记号而非运算符。

## 4 语句

### 4.1 定义与赋值

```jikuai
定义 赵甲 = 1。       -- 首次定义
赵甲 = 2。            -- 重新赋值（裸赋值）
赋值 赵甲 = 3。        -- 显式赋值关键字
设为 赵甲 = 4。        -- 同义词
自身.字段 = 5。        -- 字段赋值（类内）
赵表【0】 = 9。        -- 索引赋值
```

### 4.2 条件

```jikuai
如果 大于 赵甲 10 那么：
  打印 "大"。
否则如果 大于 赵甲 5 那么：
  打印 "中"。
否则：
  打印 "小"。
。
```

真值语义与 Python 一致：`空` / `假` / `0` / `0.0` / `""` / 空列表为假。

### 4.3 循环

```jikuai
-- 条件循环
当 小于 赵i 10：
  赵i = 加 赵i 1。
。

-- 遍历
遍历 赵i 于 范围 1 11：
  打印 赵i。
。

遍历 赵项 于 赵列表：
  打印 赵项。
。

-- 计数循环
重复 3 次：
  打印 "嗨"。
。
```

循环控制：`跳出`（break）、`跳过`（continue）。

**作用域**：`如果` / `当` / `重复` / `遍历` 块**不**引入新作用域——块内
`定义` 的名字在块外仍可见（与 Python 一致，不同于 C/Java）。

## 5 函数

```jikuai
函数 赵阶乘 接收 赵n：
  如果 小于等于 赵n 1 那么：
    返回 1。
  否则：
    返回 乘 赵n 赵阶乘(减 赵n 1)。
  。
。

打印 赵阶乘(5)。      -- 120
```

- 参数用 `接收` 引出，多参数以空格分隔：`函数 甲 接收 赵x 赵y：`
- `返回` 无值时返回 `空`；函数体走完未 `返回` 也返回 `空`。
- 递归支持（如上例）。
- 闭包：函数捕获定义处的环境。

## 6 面向对象

### 6.1 类定义、继承、构造、方法

```jikuai
类 动物：
  构造 接收 赵名字：
    自身.名字 = 赵名字。
  。
  方法 叫：
    返回 "..."。
  。
  方法 介绍：
    返回 拼接 自身.名字 "说" 自身.叫()。
  。
。

类 狗 继承 动物：
  方法 叫：              -- 覆写父类方法（多态）
    返回 "汪"。
  。
。

定义 赵狗 = 新建 狗("旺财")。
打印 赵狗.介绍()。      -- 旺财说汪
```

- `自身` 在构造器与方法体内指向当前实例。
- 未显式定义 `构造` 时沿继承链回溯父类构造器。
- **方法解析最派生优先**：`介绍` 定义在父类，但它调用的 `自身.叫()`
  解析到子类覆写版本——这就是多态。
- **词法作用域（ADR-22）**：方法体的父环境是**定义该方法的类**所在模块的
  环境，而不是调用者作用域。跨模块用对象时方法仍能看到自己模块 `导入` 的名字。

### 6.2 零参方法：访问即调用

```jikuai
打印 赵狗.叫。      -- 等价于 赵狗.叫()
打印 赵狗.叫()。
```

### 6.3 私有成员（M9）

**以「私」开头的字段与方法只能经 `自身.` 访问**，类外访问抛错：

```jikuai
类 账户：
  构造 接收 赵初始：
    自身.私余额 = 赵初始。
  。
  方法 查余额：
    返回 自身.私余额。      -- 类内：合法
  。
。

定义 赵户 = 新建 账户(100)。
打印 赵户.查余额()。      -- 100
打印 赵户.私余额。        -- 错误：私有成员不可从外部访问
```

判定看的是**语法上的接收者**（是否写作 `自身.`），不是运行时对象身份——
否则把实例存进字段再绕回来访问就能破防。

选择命名约定而非新关键字，是为了不扩张关键字/动词表（那会影响无空格分词的
最长匹配行为）。

### 6.4 反射（M9）

```jikuai
打印 是否是 赵狗 "狗"。      -- 真
打印 是否是 赵狗 "动物"。     -- 真（沿继承链，isinstance 语义）
打印 是否是 赵狗 "猫"。      -- 假
打印 是否是 42 "动物"。      -- 假（非实例一律为假，不报错）
打印 类名 赵狗。            -- 狗
```

`类名` 作用于非实例时抛类型错误（返回空串会让调用方误以为存在空名类）。

### 6.5 尚不支持

抽象类 / 接口、属性装饰器、多重继承、显式父类方法调用（`super`）、
类变量（静态字段）。绑定方法不能赋值/传参/返回（DP-3）。

## 7 异常

```jikuai
尝试：
  抛出 "出错了"。

```

`捕获` 与 `最终` 都可省略（但至少要有一个）。

## 8 模块

### 8.1 导入与导出

```jikuai
-- 工具.jk
函数 平方 接收 赵甲：
  返回 乘 赵甲 赵甲。
。
导出 平方。
```

```jikuai
-- 主程序
导入 工具。
打印 工具.平方(5)。      -- 25

从 工具 导入 平方。      -- 按名导入
打印 平方(5)。
```

**只有 `导出` 的名字对外可见**，其余访问报 `JK-E5002`。

### 8.2 模块解析顺序

1. 当前 `.jk` 文件所在目录
2. 项目根 `极快_包/`（M8 包管理，见 [§8.4](#84-包管理-m8)）
3. 内置 `stdlib/`
4. `JIKUAI_PATH` 环境变量列出的目录
5. 项目根 `极快_包/<包名>/<入口>`（包目录形态）

同一绝对路径只执行一次（缓存）；循环导入会报出完整链路。
模块名不允许含 `/` `\` `..`。

### 8.3 混合模块（ADR-16）

`X.jk` 可配一个同名 `X.py` 作为内部实现，加载器会把 `.py` 里的公共可调用
对象注入模块环境。`.jk` 仍是唯一对外门面——未 `导出` 的注入名依旧不可见。
标准库 7 个模块都用这个形态。

### 8.4 包管理（M8）

```bash
jk 包 初始化 我的应用
jk 包 添加 甲 --路径 ../甲
jk 包 装
jk 包 列表
```

- 清单 `包.json`，锁文件 `包.锁`，安装目录 `极快_包/`
- 依赖来源：`路径` / `仓库`(git) / `注册表`（未上线）
- 版本约束：`^` `~` `>=` `<=` `>` `<` `==` `*`，逗号表逻辑与

完整语义见 [`docs/包管理.md`](包管理.md)。

## 9 管道与副词

### 9.1 逗号管道

逗号把上一步的结果作为下一步动词调用的**第一参数**：

```jikuai
打印 【1, 2, 3】，求和。            -- 6
打印 【3, 1, 2】，排序，首个。       -- 1
打印 "a b c"，分割 " "，长度。       -- 3
```

### 9.2 副词：皆 / 只 / 归

高阶函数，作用于列表：

| 副词 | 语义 | 例子 |
|---|---|---|
| `皆` | map | `【1,2,3】，皆 乘 2` → `【2,4,6】` |
| `只` | filter | `【1,2,3,4】，只 大于 2` → `【3,4】` |
| `归` | reduce | `【1,2,3】，归 加 0` → `6` |

```jikuai
打印 【1, 2, 3, 4, 5】，只 大于 2，皆 乘 10，归 加 0。   -- 120
```

副词内部只接受**内建动词**。写了未知动词时静态检查会发 `JK-W1001` 警告
并给出同源动词纠错建议（见 [`docs/诊断编码表.md`](诊断编码表.md)）。

## 10 内建动词表

`元数` 列：正数 = 固定元数；`-1` = 变参（1+）；`-2` = 副词（特殊解析）。

**算术**
- `加` `减` `乘` `除` `取余` `幂` `整除` — 2
- `加上` `减去` `乘以` `除以` — 2（口语化别名）
- `负` `绝对值` — 1

**比较**
- `等于` `不等于` `大于` `小于` `大于等于` `小于等于` — 2

**逻辑**
- `且` `或` — 2；`非` — 1

（`且` / `或` 返回操作数本身而非布尔，与 Python 一致）

**列表 / 序列**
- `列` — -1；`范围` — -1
- `长度` `首个` `其余` `末个` `反转` `排序` `去重` — 1
- `追加` `连接` `包含` `取值` — 2

**聚合**
- `求和` `最大` `最小` `平均` — 1

**字符串**
- `拼接` — -1
- `分割` `替换`(3) `子串`(3) — 见元数
- `大写` `小写` `转字符串` `转整数` `转小数` `去空白` — 1

**I/O**
- `打印` `输入` — -1；`读取` — 1；`写入` — 2

（`读取` / `写入` 的语义与安全约束见 [§10.1](#101-文件-io读取--写入)）

**副词**
- `皆` `只` `归` — -2

**面向对象反射（M9）**
- `是否是` — 2；`类名` — 1

**中国特色** — 见 [§11](#11-中国特色能力)

权威表在 `src/jikuai/keywords.py` 的 `VERB_ARITY`。

### 10.1 文件 I/O：`读取` / `写入`

```jikuai
写入 "out.txt" "你好极快"。        -- 返回写入的内容，可继续入管道
打印 读取 "out.txt"。              -- 你好极快
定义赵N=写入 "out.txt" "甲乙"，长度。   -- 赵N = 2（管道拿到的是内容）
```


| 动词 | 元数 | 签名 | 返回 |
|---|---|---|---|
| `读取` | 1 | `读取 路径` | 文件全文（字符串） |
| `写入` | 2 | `写入 路径 内容` | **写入的内容**（不是字节数） |

- **编码固定 UTF-8**，无编码参数。极快源码本身要求 UTF-8，再加一个几乎
  永远填 `utf-8` 的位置参数没有收益。
- `写入` 是**覆盖**语义（`'w'`），不追加；返回内容而非字节数，是为了让它能
  出现在管道中间。
- `写入` **不自动建目录**。目标目录不存在直接报错，避免路径拼错却被静默补齐。
- 非字符串内容按 `打印` 的同一套格式化规则转字符串（`空` / `真` / `假`）。

#### 安全约束（不可关闭）

两个动词共用一把路径闸，与 `jikuai.load` 复用同一个判定函数
（`pybridge._validate_script_path`）：

1. **路径必须落在当前工作目录（CWD）内**。以下一律拒绝：
   - 绝对路径（`/etc/passwd`、`C:\Windows\...`）
   - 含 `..` 段的穿越路径（`../../secret.txt`）
   - 跨盘符（Windows）
2. **`读取` 有 10 MiB 单文件上限**。`读取` 整段吞入内存，不设顶时误指向大
   二进制会瞬间耗尽内存。超限即拒，不做截断读——静默截断比报错更危险。

已知盲点（不视为缺陷）：判定基于 `os.path.abspath` 的**词法**归一，不做
`realpath` 解析，所以 **CWD 内指向外部的 symlink / junction 不会被挡下**。
`.jk` 源码等同可执行代码，能在 CWD 里放软链的人本来就能通过 `蟒:` 桥做任意
事，这道闸的目标是拦误操作与朴素穿越，不是对抗恶意代码。


被拒时抛中文运行错误诊断，诊断码 `JK-E4002`（路径）/ `JK-E4003`（超限），
消息中的绝对路径已脱敏。登记见
[`docs/诊断编码表.md`](诊断编码表.md)，边界总声明见
[`docs/安全边界.md`](安全边界.md)。

**需要越出 CWD 或流式处理大文件时**：走 `蟒:` 桥在宿主 Python 侧显式封装后
再暴露给极快（[§12](#12-python-互操作)）。这是有意的——把「放宽文件权限」
这个决定留在宿主代码里显式做，而不是给动词加一个容易被顺手打开的开关。

## 11 中国特色能力

### 11.1 内建动词

| 动词 | 元数 | 说明 |
|---|---|---|
| `人民币` | 1 | 数值 → 人民币金额 |
| `大写金额` | 1 | 数字 → 中文大写（壹贰叁） |
| `汉字数字` | 1 | 数字 → 中文小写（一二三） |
| `校验身份证` | 1 | 身份证号 → 真/假 |
| `提取身份证信息` | 1 | 身份证号 → 字典（生日/性别/地区） |
| `校验手机号` | 1 | 手机号 → 真/假 |

## 12 Python 互操作

```jikuai
导入 蟒:math。
打印 蟒:math.sqrt(16)。      -- 4.0
```

- `蟒:` 前缀路由到 Python 桥（ADR-10）。
- **Python 函数必须括号调用**（ADR-11）：裸 `math.sqrt` 报 SYNTAX 诊断。
- 同目录 `.py` 兜底：标准 `import` 失败时回退到发起导入的 `.jk` 同目录
  的 `<name>.py`（ADR-23a），隔离加载，不污染 `sys.path`。

### 12.1 类型映射

| 极快 | Python | 方向 |
|---|---|---|
| 整数 / 小数 / 字符串 / 布尔 / 空 | int / float / str / bool / None | 双向直通 |
| 列表 / 字典 | list / dict | 双向递归（字典键仅 str/int） |
| 人民币 | Decimal | 极快→Python；反向需显式 `人民币()` |
| 类实例 | opaque object | 原样传递 |
| 绑定方法 / 类对象 | — | 禁止跨界，抛类型错误 |

### 12.2 安全边界

**不是沙箱**，只适用于可信代码。黑名单拦截 `os.system` / `subprocess.Popen`
/ `builtins.eval` / `builtins.exec`；异常消息做路径脱敏。
详见 [`docs/安全边界.md`](安全边界.md)。

## 13 已知边界

### 13.1 标识符

- **不接受中英混排**：`自身.AI可用` 会被切成 `AI` + 残余 `可用`。
  命名请纯中文或纯英文。
- **不能夹带内建动词/副词字**：`赵只在主程序里` 会在 `只`（副词）处断开；
  `助手.相加` 会在 `加`（动词）处断开。命名时避开动词字。

### 13.2 未实现的语言特性

详见 [`BACKLOG.md`](BACKLOG.md) §6（全量待办真源，含优先级）。摘要如下：

- 抽象类 / 接口 / 属性装饰器 / 多重继承 / 显式 super 调用 / 类变量
- 中缀运算符（设计上不提供）
- 泛型、类型注解、类型检查

### 13.3 AOT 编译（实验性）

`tools/aot` 可把 `.jk` 编译为原生二进制，但只覆盖子集：

- **支持**：算术/比较/逻辑/打印共 24 个动词、变量、人民币字面量、
  条件分支（`如果`/`否则如果`/`否则`）、`当` 循环、`重复 N 次`、
  `跳出`/`跳过`（M9 新增控制流）
- **不支持**：`遍历`、用户函数、类、异常、管道、副词、模块、列表、字典

超出子集时报 `JK-E7001` 并**拒绝产出任何文件**。详见 [`docs/AOT.md`](AOT.md)。

### 13.4 调试

DAP 适配器支持行断点、`next`/`stepIn`/`stepOut`、`continue`/`pause`、
调用栈与变量查看。**不支持**条件断点、`evaluate`、`setVariable`、多线程。
VS Code 集成见 [`docs/教程/07-开发工具链.md`](教程/07-开发工具链.md)。
