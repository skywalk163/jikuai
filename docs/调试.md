# 极快语言 · 单步调试指南（v0.7.0 · M6-P3）

> ADR-20 · MVP 能力边界

## 启动方式

```bash
python -m jikuai_dap
```

适配器进程通过**本机 stdio** 与调试客户端按 DAP（Debug Adapter Protocol）交互。
**不监听网络端口**。信任前提参见 `docs/安全边界.md` 第 3 节。

---

## 本版本支持的能力

| 能力 | 说明 |
|------|------|
| 行断点 (`setBreakpoints`) | 在指定源码行设置一个或多个断点 |
| 单步 `next` / `stepIn` / `stepOut` | 逐条 / 深入 / 跳出 |
| `continue` / `pause` | 恢复执行 / 请求暂停 |
| `stackTrace` | 返回当前帧（最小实现：单帧） |
| `scopes` + `variables` | 返回当前作用域全部变量名与值 |
| `threads` | 单线程模型，固定返回一个 |

---

## 本版本不支持的能力（`JK-E8001`）

以下请求将收到 `success: false`，`message` 含 "暂不支持" 与 `JK-E8001`：

- 条件断点（`condition` / `hitCondition` / `logMessage`）
- 表达式求值（`evaluate`）
- 设置变量（`setVariable`）
- 多线程 / 多会话
- 函数断点 / 数据断点 / 异常断点

## DAP 请求/响应示例

### setBreakpoints

请求：
```json
{
  "seq": 3,
  "type": "request",
  "command": "setBreakpoints",
  "arguments": {
    "source": {"path": "G:/jikuai/examples/hello.jk"},
    "breakpoints": [{"line": 2}]
  }
}
```

响应：
```json
{
  "seq": 4,
  "type": "response",
  "request_seq": 3,
  "success": true,
  "command": "setBreakpoints",
  "body": {
    "breakpoints": [{"verified": true, "line": 2}]
  }
}
```

### stackTrace（暂停态）

请求：
```json
{
  "seq": 8,
  "type": "request",
  "command": "stackTrace",
  "arguments": {"threadId": 1}
}
```

响应：
```json
{
  "seq": 9,
  "type": "response",
  "request_seq": 8,
  "success": true,
  "command": "stackTrace",
  "body": {
    "stackFrames": [
      {"id": 1, "name": "主程序", "line": 2, "column": 1,
       "source": {"name": "hello.jk", "path": "G:/jikuai/examples/hello.jk"}}
    ],
    "totalFrames": 1
  }
}
```

### variables（暂停态）

请求：
```json
{
  "seq": 10,
  "type": "request",
  "command": "variables",
  "arguments": {"variablesReference": 1000}
}
```

响应：
```json
{
  "seq": 11,
  "type": "response",
  "request_seq": 10,
  "success": true,
  "command": "variables",
  "body": {
    "variables": [
      {"name": "王甲", "value": "100", "type": "整数", "variablesReference": 0},
      {"name": "王乙", "value": "￥50.25", "type": "人民币", "variablesReference": 0}
    ]
  }
}
```

## VS Code 接入

在 `.vscode/launch.json` 中添加：

```json
{
  "version": "0.2.0",
  "configurations": [
    {
      "type": "jikuai",
      "request": "launch",
      "name": "极快调试",
      "program": "${file}"
    }
  ]
}
```

需要对应的 VS Code 扩展（`editors/vscode/` 并行支线实现）注册 `jikuai` debug type
并声明 debugger adapter 为 `python -m jikuai_dap`。

> 注意：VS Code 扩展侧的实现是并行支线（M6-P4），本文档只描述 DAP 适配器侧的协议规范。

---

## 安全与信任前提

引用 `docs/安全边界.md` 第 3 节：

- DAP 走本机 stdio，不监听网络端口
- 调试会话通道未加密未鉴权
- 不要在共享主机上让不受信任的用户接入你的调试会话

---

## 已知限制

1. 仅支持单帧 stackTrace（无嵌套函数调用栈展示）
2. 变量展示仅限当前作用域链（不支持展开复杂对象的子属性）
3. `stepOut` 基于环境链深度近似，存在边界 case
4. 人民币值统一显示为 `￥xx.xx` 格式
5. 调试执行在独立 daemon 线程，程序若有无限循环需手动 `disconnect`
