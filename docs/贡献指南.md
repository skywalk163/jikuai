# 极快·块生态贡献指南

面向想给 `stdlib/blocks/` 加一个新块（或改一个既有块）的贡献者。目标：从零起一个合规块只花一分钟，配合 `jk 块 新建` 脚手架。

深入原理见 [ADR-15 块生态架构](ADR-15-块生态架构.md) 与 [块生态.md](块生态.md)；本文只讲**你要动手时该做什么**。

---

## 1 新建块的三步

### 步骤 ①：脚手架一步出三件套

```bash
jk 块 新建 --领域 工具 --名 测试块 [--导出 测块] [--参 赵文 赵数]
           [--层级 0] [--稳定性 experimental] [--依赖 工资条 日序]
```

产出（`stdlib/blocks/<领域>/<块名>/`，UTF-8 + LF）：

| 文件         | 内容                                                                 |
| ------------ | -------------------------------------------------------------------- |
| `块.json`    | `名称/版本(0.1.0)/层级/领域/描述(TODO)/[输入]/输出/导出/[依赖块]/稳定性` |
| `<块名>.jk`  | `[从 blocks.X.Y 导入 Z。]` + `函数 <导出名> 接收 <形参...>：` 骨架 + `导出 <导出名>。` |
| `测试.jk`    | `从 blocks.<领域>.<块名> 导入 <导出名>` + 空占位调用                 |

**`--依赖`（W30 新增，写聚合块必用）**：收变长的**叶名**列表（不是点分全名，
口径同 ADR-28 §3.4 与 G11）。脚手架会

1. 把它们写进 `块.json` 的 `依赖块`；
2. 在块库里解析每个叶名的领域与导出名，**自动生成对应的 `从 blocks.<领域>.<叶名>
   导入 <导出名>。`**——所以一落地就过 G11 的「`依赖块` ↔ `导入` 对账」，不必手补。

解析不到的叶名当场整体拒绝（不产生半个块）。写 L3 时配合 `--层级 3`：

```bash
jk 块 新建 --领域 财务 --名 报销单 --导出 报单 --层级 3 \
           --参 赵明细 赵年 赵月 赵日 赵月薪 赵生年 赵生月 赵生日 \
           --依赖 工资条 求和 日序 金额雅写
```

**脚手架的三层预检全部前置**（一条不过整体退出，不落半个文件）：

1. **块名**过 `check_module_segment_atomicity`（单 token 即可，`求和` 这类 VERB 合法）
2. **导出名**过 `check_export_atomicity`（必须单 IDENT——调用方分词时看不到本模块的导出名，非 IDENT 名一律被切碎）
3. **每个形参名**过 `check_export_atomicity`（首字须百家姓且整体单 IDENT）

`--依赖` 的每个叶名走**块名那套**（单 token），不是导出名那套——它是路径段，不是标识符。


不给 `--导出` 时导出名默认等于块名。所以块名叫 `求和`（合法目录名）时脚手架会拒——`求和` 是 VERB，做不了 IDENT；必须再给 `--导出 汇总`（这也是 `stdlib/blocks/数据/求和/` 的既有惯例：目录名与导出名刻意分离）。

英文别名：`jk 块 new / init`。

### 步骤 ②：编辑 `.jk` 落实现

- 骨架里的 `-- TODO: 实现` 和 `返回 空。` 是占位；替换成真逻辑
- 元数据的 `描述` 与 `输入`/`输出` 的 `类型` 都是 `TODO` / `任意` 占位——**必须细化**，`任意` 会挂 G14 门禁
- 如果这个块聚合了别的块，`导入` 一次就在 `块.json` 的 `依赖块` 里加一项——G11 门禁会拿两边对账
- 需要 Python 背衬时按 [ADR-16 §3.3 混合模块](ADR-16-标准库契约.md) 补 `<块名>.py`；脚手架默认不生成

### 步骤 ③：校验合规

```bash
jk 块 校验 stdlib/blocks/<领域>/<块名>/     # 单块
jk 块 校验                                   # 全量
```

校验项（`validate_block`）：元数据合法 / 主 `.jk` 存在 / 至少一个 `导出` / 导出名词法原子 / `块.json.导出` 与 `.jk` 一致 / `依赖块` 与 `导入` 一致 / `测试.jk` 存在（缺失是警告）。

改了块之后**必跑**：`python scripts/generate_block_index.py` 刷索引；改了元数据的还得跑 `tools/ai-bridge/generate_embeddings.py` 刷向量索引（本机不联网请设 `HF_HUB_OFFLINE=1`）。

## 2 命名词库速查表

极快是免空格分词，分词器会把内建动词/关键字从任意字串里切出来。给块起名的三条铁律：

- **变量名首字必须是百家姓姓氏**（`赵钱孙李…`）且整体是单 IDENT。`赵列表` 会被切成 `赵`+`列`(VERB)+`表`——`列` 是列表构造动词。写 `赵项表` / `赵数值`
- **导出名不能含内建动词字样**——非原子名调用方一侧永远拿不到
- **块目录名比导出名松**，允许单个 VERB/KEYWORD（`求和` 合法），但两个及以上 token 拼起来死（`配置加载` = `配置`+`加`+`载`）

### 2.1 常见踩坑（含实际切分结果，逐条自检过）

| 名字        | 词法切分                              | 用作导出名？ | 用作目录名？ |
| ----------- | ------------------------------------- | ------------ | ------------ |
| `汇总`      | `汇总(IDENT)`                         | ✓            | ✓            |
| `求和`      | `求和(VERB)`                          | ✗            | ✓            |
| `块求和`    | `块(IDENT)+求和(VERB)`                | ✗            | ✗            |
| `累加`      | `累(IDENT)+加(VERB)`                  | ✗            | ✗            |
| `归并`      | `归(ADVERB)+并(IDENT)`                | ✗            | ✗            |
| `赵列表`    | `赵(IDENT)+列(VERB)+表(IDENT)`        | ✗（形参）    | —            |
| `赵次`      | `赵(IDENT)+次(KEYWORD)`               | ✗（形参）    | —            |
| `配置加载`  | `配置(IDENT)+加(VERB)+载(IDENT)`      | ✗            | ✗            |

### 2.2 保留字不能做导出名

内建动词字样一律禁：`加/减/乘/除/列/求和/最大/最小/平均/长度/排序/连接/包含/反转/替换/分割/拼接/追加/去重/取值/子串/大写/小写/转字符串/转整数/转小数/去空白/打印/输入/读取/写入`。

内建副词也禁：`只 / 皆 / 归`。

类型词/字面量也禁：`整数 / 小数 / 字符串 / 布尔 / 列表 / 字典 / 元组 / 空 / 真 / 假 / 人民币 / 日期 / 农历`。

关键字也禁：`函数 / 接收 / 返回 / 定义 / 如果 / 那么 / 否则 / 循环 / 从 / 导入 / 导出 / 类 / 父类 / 我 / 抛 / 试 / 捕获`。

**完整清单以 `src/jikuai/keywords.py`（关键字 + 动词元数表）与 `src/jikuai/surnames.py`（可用姓氏表，注意 `CONFLICTING_SURNAMES` 里的 `空/非/真/假/长/大/小/于` 不能当姓用）为准**——本表只是速查，词表升级时以代码为唯一真源。

### 2.3 推荐词库（实测原子）

`汇总 合计 聚合 总和 清洗 规整 解析 编码 校对 裁剪 采集 落盘 装载 整合 融合 编排 格式 转换 校验 抽取 提取 摘要 扫描 搜集 产出 处理 融汇 凝合`

命名前**一律**自己跑一遍：

```bash
python -c "import sys; sys.path.insert(0,'src'); from jikuai.pkg.blocks import check_export_atomicity; \
print(check_export_atomicity('汇总'))"
# → (True, [('IDENT', '汇总')])
```

或直接用 `jk 块 新建`——脚手架的预检会替你把关。

## 3 CI 门禁清单（PR 必绿）

`.github/workflows/ci.yml` 上跑的六条门禁，任一红都进不了 main：

| 门禁 | 名称                            | 校验点                                                        | 触发脚本                                             |
| ---- | ------------------------------- | ------------------------------------------------------------- | ---------------------------------------------------- |
| G10  | 全量 pytest                     | `tests/` 全绿；块的 `测试.jk` 也在 `test_blocks_smoke.py` 里跑 | `python -m pytest tests/ -q`                         |
| G11  | 索引一致性                      | `stdlib/blocks/索引.json` 与 `scan_blocks()` 实况一致；`依赖块` ↔ `导入` 对账 | `python scripts/check_stdlib_contract.py`            |
| G12  | 向量索引同源                    | `向量索引.元信息.json` 里的块内容哈希与实算一致（换了元数据要重跑 embeddings） | `python tools/ai-bridge/generate_embeddings.py`      |
| G13  | 导出名全局唯一                  | 索引里所有块的 `导出` 名两两不重复                            | `check_export_globally_unique()`（走 G11 一并跑）     |
| G13+ | L3 聚合契约（ADR-28）           | `依赖块` 图无环；声明 L3 的块依赖结构真够 L3；stable L3 的 L2+ 依赖也是 stable | `check_dependency_acyclic()` / `check_level_consistency()` / `check_stability_propagation()`（走 G11 一并跑） |
| G14  | stdlib 块类型精度               | `输入`/`输出` 的类型不能停在裸容器（`列表` 要给 `元素类型`）  | `check_stdlib_type_annotations()`（走 G11 一并跑）   |
| G15  | 版本号一致性                    | `_version.__version__` / `pyproject` / `CHANGELOG` / `vscode/package.json` 四处一致 | `_check_version_consistency()`（走 G11 一并跑）     |

改了元数据没重跑向量索引 → G12 红；索引没重生成 → G11 红。**忘记刷索引是最常见的返工原因**。

### 提交规约（W26 · v0.16.0 起）

Windows/PowerShell 环境下**禁止**用 bash heredoc 写 commit message。正确写法：

```powershell
# 方式一：从文件读
git commit -F commit_msg.txt

# 方式二：多个 -m
git commit -m "feat: 标题" -m "正文段落"
```

`scripts/check_commit_msg.py` 可作为 pre-commit hook 挂上（可选，CI 暂不强制）。

## 4 PR 模板

### 标题格式

```
feat(blocks/<领域>): <块名> — <一行描述>
```

例：`feat(blocks/数据): 融合 — 合并两个数值列表并去重`

### 描述模板

```markdown
## 做了什么
<一句话说明这个块解决了哪个具体场景。不要复述块名。>

## Checklist（合入前逐项打勾）

- [ ] `jk 块 新建` 起的三件套，未手改脚手架的强制结构
- [ ] `块.json` 过 `jk 块 校验 <块目录>`：零 error，零 warning
- [ ] `.jk` 里有实际实现，`返回 空` / `-- TODO` 全部替换
- [ ] `块.json.描述` 是**一句话可读中文**，不是 `TODO`
- [ ] `块.json.输入`/`输出` 类型细化到 ADR-26 精度（无裸 `列表` / `字典`）
- [ ] 导出名过 `check_export_atomicity`，且不与索引里既有导出名重名（G13）
- [ ] 依赖别的块的话，`依赖块` 字段与 `.jk` 里的 `导入` 语句完全一致
- [ ] `测试.jk` 有真实断言（不是脚手架的 `打印 赵结果`），能过 `test_blocks_smoke.py`
- [ ] 重跑 `python scripts/generate_block_index.py`，索引一并提交
- [ ] 改了元数据的：重跑 `python tools/ai-bridge/generate_embeddings.py`（`HF_HUB_OFFLINE=1` 若本机无网）

## 为什么不复用既有块
<如果与既有块场景相似，说明差异；否则删除本段。>
```

## 5 交接文档六个坑 × 贡献者注意事项

摘自 [`docs/M2-块库扩容-WBS.md` §2](M2-块库扩容-WBS.md)。开工前一定要过一遍。

### 坑 #1：极快没有中缀运算符

`+ - * /` 一律是前缀动词：`加 减 乘 除 取余 幂 整除 绝对值 负`。复利 `本金 × (1+利率)^期数` 写成：

```jikuai
乘 赵本金 幂 加 1 赵利率 赵期数。
```

**贡献者动作**：写数学表达式前先在 REPL 试算。中缀顺序拿不准时用括号明示：`(加 1 赵利率)`。

### 坑 #2：没有内建的四舍五入 / 取整

`四舍五入 / 向上取整 / 保留N位` 都不存在。金额舍入两条路：

- 用内建 `人民币` / `￥` 字面量（内部 `Decimal + ROUND_HALF_UP`，中国会计惯例）
- 加 `.py` 背衬（ADR-16 §3.3；参考 `stdlib/blocks/工具/深拷贝`）

财务领域已经有 `blocks.财务.保留分`，其它财务块**必须依赖它**，不要各自实现分位处理。

**贡献者动作**：写财务/统计块时，第一步检查是否需要 `保留分`；写通用数据块时避免自造 rounding。

### 坑 #3：内建 `读取` / `写入` 限制在 CWD 内

v0.16.0 W28 起两个动词**已实现**（UTF-8、`写入` 返回写入内容），但路径必须
落在当前工作目录内：绝对路径、`..` 穿越、跨盘符一律拒（`JK-E4002`）；
`读取` 另有 10 MiB 上限（`JK-E4003`）。没有放宽开关。

`blocks.数据.载入` / `blocks.数据.存文` 仍在，现在是这两个动词的纯 `.jk` 门面。

**贡献者动作**：块里的文本读写直接用 `读取` / `写入`，或复用
`blocks.数据.载入` / `blocks.数据.存文`；路径一律写**相对 CWD** 的形式。
要越出 CWD 或流式处理大文件，走 `蟒:` 桥在宿主侧显式封装，不要试图绕闸。


### 坑 #4：变量名首字须百家姓 + 词法原子

`赵列表 → 赵+列(VERB)+表` 报错。现有块统一 `赵数值 / 赵项表 / 赵结果`。

**贡献者动作**：形参名一律走 `jk 块 新建 --参 赵… 赵…` 的预检；预检拒了就换字，不要绕。可用姓氏表见 `src/jikuai/surnames.py`。

### 坑 #5：保留字不能做导出名

`整数 小数 字符串 布尔 列表 字典 人民币 日期` + 全部内建动词。目录名可以叫 `复利`，导出名要另取（`滚利`）。

**贡献者动作**：命名前跑 §2 自检；实在拿不准就 `jk 块 新建`——脚手架预检会替你挡下。

### 坑 #6：`测试.jk` 已经有 runner

v0.13.0 起 `tests/test_blocks_smoke.py` 参数化扫全部 `stdlib/blocks/**/测试.jk`，逐个 `run_source` 跑。这意味着：

- 脚手架产的 `打印 赵结果` 占位测试就是绿的（`返回 空` 打印 `空` 不崩）
- **改完实现后必须补真实的断言**——否则 CI 绿等于零覆盖，接手的人会踩你没测的边界

**贡献者动作**：`测试.jk` 至少覆盖一条 happy path + 一条边界；PR 中的「测试用例数」应 > 1。

## 5.5 内建动词/字面量语义补充（写实现前先记住）

§5 六个坑管的是**命名与结构**；这一节管**写 `.jk` 实现时容易用错语义的内建**。
详细词表以 `src/jikuai/keywords.py` 为唯一真源，本节只挑贡献者最常踩的几处。

### `打印` 是变参，`拼接` 是变参 concat（不是 join）

- **`打印` 收变长实参**：`打印 "个税：" 赵税额 "元"。` 一句可打多个值，
  不需要先自己拼字符串。测试.jk 里想核对多个中间量时直接 `打印` 一串即可。
- **`拼接` 是变参 `concat`，不是带分隔符的 `join`**：`拼接 赵甲 赵乙 赵丙` 把
  若干序列/字符串**首尾相接**，中间**不插分隔符**。想要 `"a,b,c"` 这种带分隔
  符的效果，得自己在元素间塞分隔符，或走 `网络.表单串` / `网络.记法织串` 这类
  专门的块——不要指望 `拼接` 帮你加逗号。

### `连接` / `包含` / `反转` / `替换` 是内建动词，不是块，也不是导出名

这四个是 lexer 直接识别的内建 VERB（见 §2.2 禁用清单）：

- 它们**已经能用**，别再去 `stdlib/blocks/` 造同名块，也别拿它们做导出名/形参名
  （非原子，调用方一侧拿不到）。
- 尤其 `连接` 指的是内建的序列/字符串连接动词，**语义上并不等于其它语言的
  `join`**；需要「用分隔符把列表拼成一个字符串」时同样得自己处理分隔符或走
  网络域的织串类块。

### `示例` 字段里字符串用中文引号 `“…”`

- `块.json` 的 `示例` 字段（以及文档里贴的示例代码）如果要展示字符串字面量，
  推荐写中文引号 `“你好”`——极快 lexer 对中文引号 `“…”` 与 ASCII 引号 `"…"`
  **同义**（见 `docs/语法参考.md` §2 字面量表），中文引号在中文语境里更协调，
  也避免和 JSON 外层的 ASCII 双引号打架需要转义。
- 反过来，`示例` 只是给人看/给检索用的样板，**不进 TF-IDF/神经语料也不做运行时
  校验**（`_INDEX_ENTRY_KEYS` 不投影它，见 `块生态-v0.12.0复盘` 与检索调优记录），
  所以写得贴近真实调用即可，不必强求可直接 `run`。

## 6 一分钟速通清单（打印钉在墙上）

1. `jk 块 新建 --领域 X --名 Y --导出 Z --参 赵甲 赵乙`
2. 编辑 `Y.jk`：删 `-- TODO`，写实现，替换 `返回 空`
3. 编辑 `块.json`：写描述，细化 `输入`/`输出` 类型
4. 编辑 `测试.jk`：至少 2 条断言（happy + 边界）
5. `jk 块 校验 stdlib/blocks/X/Y/` → 全绿
6. `python scripts/generate_block_index.py`
7. `python tools/ai-bridge/generate_embeddings.py`（改了元数据才要）
8. `python -m pytest tests/ -q` → 全绿
9. PR，套 §4 模板

祝顺利。
