# 极快 JiKuai v0.12.0 路线图 · 块生态 3 个月并行开发计划

- 版本：v0.12.0 起步（面向 v0.13.0 收官）
- 周期：12 周（3 个月）
- 起草日期：2026-08-09
- 关联：ADR-15（块生态架构）、路线图.md（主线）

---

## 一、目标与非目标

### 目标（本季度必达）

1. **块元数据基础设施可用**：`块.json` 规范落地，`module_loader` 支持点分路径，`jk 块 ...` CLI 就绪
2. **首批 40 个稳定块**：数据/中文/网络/工具四个领域各 10 个原子块（层级 0）
3. **首批 12 个一级组合块**：每个领域 3 个（层级 1），验证组合模式可行
4. **AI 桥接协议原型**：`索引.json` 自动生成 + 一个参考实现（读取索引 → 输出粘合代码）
5. **零回归**：现有 1372+ 测试全绿；新增测试 ≥ 300 条

### 非目标（明确不做）

- 可视化拖拽搭建界面
- 云端块仓库
- 块模板/代码生成器
- 强类型运行时校验

## 二、四条并行轨道

四条轨道**读写域尽可能不相交**，可 4 个开发者/AI Agent 同时推进。每周尾做一次跨轨集成（周会+集成测试）。

| 轨道 | 主责域 | 主要产出 | 依赖前置 |
|------|--------|----------|----------|
| **A · 内核** | `src/jikuai/module_loader.py`、`src/jikuai/pkg/blocks.py` | 点分路径解析、块元数据加载、CLI 子命令 | 无 |
| **B · 块库** | `stdlib/blocks/`（新目录） | 40 个原子块 + 12 个一级块 + 测试 | 轨道 A 的 W3 里程碑 |
| **C · 工具链** | `scripts/`、`docs/`、CI | 契约校验、索引生成、文档 | 轨道 A 的 W2 里程碑 |
| **D · AI 桥接** | `tools/ai-bridge/`（新目录）、示例 | 索引→选块→粘合代码的参考实现 | 轨道 A 的 W4、轨道 C 的 W3 |

## 五、风险与应对

| 风险 | 严重度 | 应对 |
|------|--------|------|
| 块领域划分打架（同一功能应归"数据"还是"中文"） | 中 | 领域字段用**数组**，允许多归属；由 M1 决策清单固化 |
| 组合块层级判定主观 | 中 | 层级只作为提示字段，不作为强约束；CI 只校验"聚合的子块层级 < 本块层级" |
| AI 桥接协议早期定不下来 | 高 | W8 只做"关键词→选块"的最简版；智能选择留 v0.13.0 |
| 轨道 B 的块数量目标 40+12 过于激进 | 中 | 保底 24+8（各领域 6 原子 + 2 一级）；超额部分转 v0.13.0 |
| stdlib 分发膨胀 | 低 | ~~`pyproject.toml` 已用 data files 声明；块目录随 wheel 分发验证一次即可~~ **（2026-08-15 更正：这句从未兑现。`pyproject.toml` 里没有任何 data-files / package-data 声明，仓库也没有 `MANIFEST.in`，`stdlib/` 整个目录从来不进 wheel/sdist。项目一直靠 `pip install -e .` + `__file__` 相对回溯工作。见 `docs/BACKLOG.md` §10）** |
| **词法原子性约束限制块命名自由度** | **高** | **已缓解**：ADR-15 §3.7 固化约定——导出名必须整体被 lexer 识别为单个 IDENT，否则调用方报 `JK-E5002`。根因是免空格最长匹配分词，调用方分词时不知道被导入模块的导出名，ADR-09 白名单覆盖不到。**需要在所有块开发前统一命名词库**：`docs/块生态.md` §2 给出推荐词库、禁用字样与逐名自检命令；`jk 块 校验` 把原子性检查纳入入库门禁 |

## 七、成功度量

季度末交付审查按以下指标判定：

1. **可用性**：3 个 demo 端到端跑通
2. **覆盖度**：保底 24 原子块 + 8 一级块（各领域 6+2）；争取达到 40+12 的原目标，超额部分转 v0.13.0
3. **质量**：新增测试 ≥ 300 条，零回归
4. **压缩比**：AI 桥接 demo 上 token 压缩 ≥ 10 倍
5. **文档**：`docs/块生态.md` 完整，教程 ≥ 3 篇
6. **社区可参与**：`jk 块 校验` 让外部贡献者能本地自查

达成 5/6 视为季度成功；达成 6/6 视为超预期。
