# 极快 JiKuai · v0.26.0 – v0.28.0 路线图 · 制造域与口径可审计 Chat BI

> 立项 2026-08-18，承接 v0.25.0（tag `v0.25.0`/`a306e85`）。
> 触发事件是外部命题——长株潭 Agent 大赛命题赛道第三题「制造业运营态势 Chat BI Agent」。
> WBS 接 W129，本轮 **W130–W172**，跨三个版本（M27 / M28 / M29），约 6–9 个月。

---

## 一、这一轮和以往都不同：方向由外部命题给出

v0.14 到 v0.25 的十二个版本，方向全部来自内部（类型系统、块生态、包管理、CI）。
本轮第一次由外部赛题定范围，因此进场先说清两件事：**这个赛题为什么值得接**，
以及**接了会不会把项目带歪**。

### 值得接的理由：评分表和项目的立项动机重合

赛题的**必选功能**里有一行「溯源说明：回答中应说明使用了哪些表、字段或查询逻辑」；
**评审重点**六维里又单列一条「可解释性：是否说明数据来源、字段、查询逻辑和结论依据」；
**加分项**里还有一条「数据质量检查，如缺失值、异常值、**口径不一致提示**」。

Chat BI 的头号失效模式是「LLM 写 SQL / 定口径，算出一个自信的错数」——这恰好是
极快的立项动机。极快的架构天然反着来：生成的 `.jk` 源码**就是**查询逻辑，块元数据
**就是**字段与口径声明，`块.json` 的 `版本` 就是口径的版本。

**本轮主张一句话：不让大模型算数，只让它选口径。**

### 不会带歪的边界

- 领域从六个扩到七个（加 `制造`），走 ADR-15 注册，**不改块元数据格式**。
- **不动语言、不动协议层**。语言级「表」一等类型明确不做（ADR-40 §3.3）。
- 引擎层不享有「确定性推链」红利，这一点在 ADR-40 §3.1 写死，
  **白皮书和对外材料不得把引擎层包装成推链成果**。

## 二、进场核实：块库对 Chat BI 的直接覆盖接近零

不是「挑几个现成块拼一下」。逐条核实（v0.25.0，块库 112）：

- `数据` 域 19 个块**全是单列标量统计**。无 group-by、无连接、无透视、无时间序列、
  无异常检测、无 CSV。
- `数据/分组` 块导出名 `聚簇`，实际是**定长切块**，不是 group-by。这是 AGENTS.md
  第四节所指「兄弟能力缺位」的现成实例——照着用会跑通、结果是错的。
- CSV 解析被项目自己写进 `tools/ai-bridge/评测集-无覆盖.json` 当「明确无覆盖」负例。
- 全仓零图表能力（`tools/web/static/index.html` 258 行里无 canvas/svg/chart 库）。

**能复用的只有三块**：历法域（日/旬/月归一、日期算术）、中文域（`排版规整`/
`金额雅写`/`数字中文` 拼中文日报）、`蟒:` 桥（CSV sidecar）。

数据规模实测有利：最大单文件 203KB，8 张表全部远小于内建 `读取` 的 10 MiB 上限。
**不需要 pandas 兜数据量**，桥只在 CSV 解析这一步用。

## 三、拍板：两层架构

| 层 | 表的表示 | 类型图 | 正确性来源 |
|---|---|---|---|
| 引擎层（关系算子） | `列表<字典<字符串,任意>>` | **不起作用**（`任意` 双向放行） | 单测 |
| 口径层（制造域指标块） | 精确元组 | 生效 | 单测 + 口径声明 + G22 |

理由与被否的三条备选（全具体元组 / 语言级表类型 / 全程 pandas opaque）见
[`ADR-40-制造域数据模型.md`](ADR-40-制造域数据模型.md) §3.3。

**这是对 8 月 18 日早先一次拍板的修正**：当时选的是「每张事实表写成固定形状元组」。
读完赛题说明后改判，依据是赛题明写「最终评审可能包含公开问题、现场追问和隐藏问题」
——只按公开 10 题写具体元组，公开题会全对，现场追问一个没覆盖的问法就翻车，
而且是「跑通了、数是错的」那种翻车。

## 四、最要紧的技术产出不是块，是口径分歧点

数据集里有两个**现成比率列**（初稿误写「三个」，实测只有 `achievement_rate` 与
`energy_per_vehicle`——见 ADR-40 §5 修正框），直接汇总会算出错数；加上一个无现成列的
缺陷率，**分歧仍是三处**。ADR-40 §5 逐条定了口径，
每处都出**两个**块、各自声明，G22 缺一个就红：

1. **平均达成率**：行级 `mean(achievement_rate)` ≠ 加权 `sum(actual)/sum(planned)`。
   默认加权。Q_PUB_005 直接考这个。
2. **单车电耗**：现成列 vs 关联 `fact_production_actual` 重算。默认现成列，重算块供
   交叉校验——Q_HID_003 需要同时看总电耗与单车电耗两条线。**实测这两个口径在本数据集上
   数值等值**（2896/2896 行逐行核对），重算块的价值是证明口径与换数据后能分叉，
   不是在本数据集上算出不同的数。
3. **缺陷率**：分子分母来自不同表，必须先按维度+窗口对齐后相除。**先算比率再平均是错的。**

这三条是整轮里最能体现「口径可审计」的东西，也是演示时最该讲的一页。

## 五、数据集自带标准答案 → 门禁 G22

数据集 `README.md` 与 `业务关系说明.md` 把 5 个预置异常连答案一起给了：
M003@L002 2026-06 焊装-焊点虚焊；L002 2026-06-10～06-24 单车电耗升高；
C005 的 M003 订单 2026-06 集中延期；L003 夜班达成率持续低于白班；
L005 2026-04-08～04-18 停线时长偏高。

G22 断言**恰好命中这 5 条，不多不少**。

评测集分档，沿用 AGENTS.md §六纪律：

- **调优集**：`question_public.csv` 10 题（带 `reference_answer`）
- **留出集**：`question_hidden.csv` 5 题。它出现在参赛者包里（赛题说明写「建议由赛事方
  保留」），本项目仍**当留出集用——只当裁判，绝不看它的 miss 明细调参**。
- **负例两档**：制造域「远离档」（问库外能力）与「近边缘档」（口径差一档），分档报数。

## 六、版本切分

### v0.26.0 · M27「引擎与语义层」· W130–W145（约 3 个月）

底座。CSV 载入、关系算子、语义层、第一批口径块、评测集、G22。
**验收：CLI 能跑通全部 10 道公开题，G22 绿。** 无 UI、无 LLM。

详见 [`v0.26.0-WBS.md`](v0.26.0-WBS.md)。

### v0.27.0 · M28「Agent 与呈现」· W146–W160（约 3 个月）

规划器（NL → `方案.json`）、拒答、多轮追问、异常识别与归因、图表块（输出 ECharts
option JSON，**不渲染图片**——照 `网络/请求组装`「不发起连接」的先例保持纯函数可单测）、
运营日报、溯源面板、等价 SQL 导出、数据质量检查。

### v0.28.0 · M29「交付与硬化」· W161–W172（约 1.5–2 个月）

演示服务安全化（见 §七）、角色视角、趋势判断、六项交付物、演示视频、全量回归与复盘。

## 七、本轮最大的风险：演示服务不能直接挂出去

赛题交付物第一条是「可运行 Demo **或在线访问链接**」。而
`tools/web/server.py` **无任何鉴权，`/api/跑` 在本机进程内执行提交的极快代码**，
经 `蟒:` 桥等于任意代码执行——AGENTS.md 第三节自己明令「不要暴露到网络」。

**W161 必须新开一个演示端点**：只收 `方案`、不收源码、块白名单、带鉴权、数据集只读挂载。
现有那套继续只作本机交互式工具。这条不许因为赶交付而跳过。

## 八、本轮明确不做

- **语言级「表」一等类型**：要动 `pkg/blocks.py` 的 `CONTAINER_TYPE_NAMES`、
  `glue.py` 的 `normalize_type`/`type_feeds`、G14，并修订 ADR-26。留 v0.29.0 后另立 ADR。
- **把引擎层也纳入类型图**：`值类型: 任意` 的退化是已知代价，不假装它被守着。
- **pandas 全链路**：数据量不需要（§二），且会架空「确定性合成层」这个卖点。
- **真 Text-to-SQL**：走语义层 + 口径块，SQL 只作为「展示查询过程」的等价导出（W159）。
- **在赛题数据集之外做通用制造业块**：口径本身是场景相关的，脱离数据集造块是凑数。

## 九、成功度量

1. **v0.26.0**：10 道公开题 CLI 全通；G22 绿且反例测试证明它抓得到（不少于 3 类反例）。
2. **v0.27.0**：5 道留出题在**没看过 miss 明细**的前提下答对；每个数字可回溯到
   「块名 + 版本 + 口径声明 + 生成的 `.jk` 源码」。
3. **v0.28.0**：六项交付物齐；演示端点带鉴权且不接受源码提交；G10–G22 全绿。
4. **反向度量**：若 §四那三个口径分歧点在演示里讲不清楚，本轮的技术主张就没兑现——
   块数量和代码行数都不算达标依据。
