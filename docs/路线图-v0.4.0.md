## 第 2 月 · M2（09-07 ~ 10-07）：Python 互操作双向桥

**目标**：让极快能双向调用 Python——极快脚本调用 Python 函数（out-bound），
Python 程序嵌入并调用极快（in-bound）。为 M3 的真实场景脚本（如调用
`requests` / `datetime` / 数据处理库）铺路。

### 任务

| 任务 | 描述 | 依赖 |
|------|------|------|
| T-20 | 独立 `src/jikuai/pybridge.py`：Python 桥核心（ADR-10） | M1 |
| T-21 | `蟒:` 前缀 lexer 支持：`蟒:模块.函数(...)` 分词 | T-20 |
| T-22 | Python 函数括号调用（ADR-11，**不进 VERB_ARITY**） | T-21 |
| T-23 | 类型编组（marshalling）：极快 ↔ Python 值互转（列表/字典/人民币/日期） | T-20 |
| T-24 | in-bound API：`import jikuai; jikuai.eval_source(src)` 返回 Python 值 | T-23 |
| T-25 | 桥安全边界：白名单模块 + 显式 `蟒:` 前缀，禁止隐式全局导入 | T-20 |
| T-26 | `tests/test_v0_4_0_pybridge.py`：out/in 双向各 ≥5 用例 | T-20..T-25 |
| T-27 | `docs/Python互操作.md`：桥语法、编组表、安全模型 | T-20..T-25 |

### 依赖关系

```
M1 完成 → T-20 → T-21 → T-22
                  ↘ T-23 → T-24
                  ↘ T-25
所有 → T-26（测试） / T-27（文档）
```

### 验收

- out-bound：`蟒:平方(4)。` → 16；`蟒:datetime.date(2026,8,7)` 编组为极快日期。
- in-bound：`jikuai.eval_source('加 3 5。')` 在 Python 侧返回 `8`。
- 类型编组：极快列表 ↔ Python list、人民币 ↔ Decimal、日期 ↔ date 双向无损。
- **安全**：未在白名单的模块（如 `os`/`subprocess`）默认不可 `蟒:` 调用；
  需显式配置放行，且文档标注风险（最小权限原则）。
- ADR-11 守恒：Python 桥函数不污染中文动词元数体系（前缀免括号写法对桥无效）。
- 回归红线：M1 的 164 项测试 + M2 新增全绿。

### 风险

- Python 桥是**新的攻击面**：任意 Python 调用可执行宿主代码。T-25 的模块
  白名单与显式前缀是硬约束，评审必须过安全审计（OWASP/STRIDE：注入、越权）。

## 优先级取舍说明

- **M1 先根治 ADR-06 副作用**：这是正确性缺陷（用户合法命名导致类外语义
  泄漏），不是优化项，越晚改影响面越大；且它是 M2 Python 桥元数隔离
  （ADR-11）的前置——动词/标识符边界必须先明确。
- **M2 做 Python 桥而非直接堆示例**：M3 的真实场景脚本（网络/日期/数据）
  大量依赖 Python 生态，先有桥才能写出有说服力的示例。
- **M3 收尾发布**：语义在 M1/M2 冻结后，M3 只做示例、文档、打包，风险最低，
  适合放在发布窗口前。
