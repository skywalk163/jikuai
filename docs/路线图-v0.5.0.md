## 5. ADR-06 X2 降级机制摘要

引用 Summary 裁决 D-06。

### 触发条件

- **T1**：副词后接非内建动词（`皆`/`只`/`归` 后的 token 不在 `VERB_ARITY` 中）→ 副词按原值透传，产出 `JK-W1001`
- **T2**：二遍分词结果不收敛（首遍与二遍的 token 序列存在差异）→ 回退首遍结果，产出 `JK-W9001`
- **T3**：首遍结果本身存在错误（如 `JK-E0001` 非法字符）→ 不进入二遍，直接报错

### 降级后 5 条强制动作

1. 产出对应的 warning 级别 `Diagnostic`（`JK-W1001` 或 `JK-W9001`）
2. 使用首遍（或原值透传）的分词结果继续执行
3. 在 stderr 输出降级提示（通过 `render_text` 渲染 warning）
4. 设置内部标志 `_degraded = True`，供下游（如 LSP）查询
5. 记录降级事件到 `DiagnosticSink`，确保 `ListSink.drain()` 包含该条目

## 6. 版本号对齐

当前需同步的版本号位置（3 处，M5 起增至 4 处）：

- `pyproject.toml` — `[project].version`
- `src/jikuai/__init__.py` — `__version__ = "x.y.z"`
- `src/jikuai/main.py` — `VERSION = "x.y.z"`
- （M5 起）VS Code 扩展 `package.json` — `"version": "x.y.z"`

门禁 G14 确保这些位置在每次发布时保持一致。
