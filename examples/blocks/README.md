# examples/blocks · 块组合示例

本目录收录用**现有极快语法**组合块的可运行示例。所有示例只用 `从 ... 导入 <导出名>`
形式引用块（唯一推荐的调用形式，见 [`docs/块生态.md` §1](../../docs/块生态.md)）。

运行方式：

```bash
python -m jikuai examples/blocks/<文件名>.jk
```

## 示例清单

以下示例**当前即可运行**（只依赖 `blocks.数据.求和` + 内建动词）：

- **基础求和.jk** —— 用 `汇总` 块对数值列表求和（含空列表边界）。预期输出 `15` / `0` / `100`
- **多步汇总.jk** —— 分组求和后再合并汇总。预期输出 `15` / `40` / `55`
- **函数封装.jk** —— 把块调用封装进自定义函数（求平均值）。预期输出 `6.0` / `5.5`
- **管道清洗求和.jk** —— 演示清洗 + 求和管道；当前用手动去零的替代实现跑通。预期输出 `9`

以下示例**待对应块落地后启用**，文件内以注释给出完整预期代码：

- **批量统计管道.jk** —— 读取文件 → 清洗 → 求和的三步管道。依赖 `blocks.数据.读取文件`（导出 `装载`）、`blocks.数据.清洗`（导出 `规整`），均 M2 交付
- **中文规范化.jk** —— 简繁转换 + 分词。依赖 `blocks.中文.简繁包装`（导出 `转简`）、`blocks.中文.分词包装`（导出 `切词`），均 M2 交付

## 命名约定说明

示例中所有块的导出名（`汇总`、`规整`、`装载`、`转简`、`切词`）都是**词法原子**的
——整体被 lexer 识别为单个 IDENT。这是块导出名的硬约束，详见
[`docs/块生态.md` §2 命名约束](../../docs/块生态.md) 与 ADR-15 §3.7。
