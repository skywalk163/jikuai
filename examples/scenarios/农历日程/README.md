# 场景：传统农历日程生成

## 用途

演示极快的**历法能力**：把一组公历日期批量转换为农历日期，并附带干支纪年与生肖。
覆盖内建动词 `公历转农历` / `干支纪年` / `生肖` / `农历完整日期`，同时展示逗号管道
（`皆生肖` / `皆干支纪年` / `只小于` / `只大于`）在历法数据上的用法。
适合作为「日程表 / 节庆提醒 / 传统历法展示」类程序的骨架。

## 输入

全部为**固定字面量**，内嵌在 `main.jk` 中，**不读取系统当前时间**，因此输出稳定可作快照：

- 单日详情：2026-08-08
- 年份表：2024 / 2025 / 2026 / 2027 / 2028
- 2026 年日程表（四条等长平行列表：年 / 月 / 日 / 事件），7 条：
  元旦 01-01、春节 02-17、清明 04-05、劳动节 05-01、端午 06-19、中秋 09-25、国庆 10-01
- 甲子循环验证：1984 与 2044
- 有效范围自检用年份：1984 / 2024 / 2025 / 2026 / 2027 / 2028 / 2044

## 预期输出

见同目录 `expected.txt`（真实运行结果的快照，37 行）。要点：

- 2026-08-08 → 干支「丙午」、生肖「马」、农历「丙午(马)年 八月十八」
- `公历转农历` 返回四元组 `[农历年, 农历月, 农历日, 是否闰月]`
- 年份表 → 生肖 `['龙','蛇','马','羊','猴']`、干支 `['甲辰','乙巳','丙午','丁未','戊申']`
- 7 条日程各自的农历日期
- 1984 与 2044 干支同为「甲子」，60 甲子循环验证通过
- 有效范围自检：越界年份列表为空

## 前置依赖

- Python 3.8+，仓库根目录下运行
- 运行方式：`PYTHONPATH=src python -m jikuai examples/scenarios/农历日程/main.jk`
- 历法能力来自纯 `.py` 模块 `stdlib/历法.py`，**无 `.jk` 门面**，因此
  `导入 历法。` 不成立；其能力全部以内建动词形式直接调用，本示例无需任何 `导入`

## 覆盖的日期范围与已知边界

**有效范围：公历 1900 - 2100**（农历数据表 `stdlib/历法.py` 的覆盖区间）。
本示例的所有查询年份（1984 - 2044）均落在此区间内。

超出范围的实测行为（**本示例不演示，仅在此声明**）：

| 输入 | `农历完整日期` 的行为 |
|------|----------------------|
| 年份 < 1900（如 1899） | **不报错，静默给出错误结果**（实测 `农历完整日期 1899 1 1` 返回 `庚子(鼠)年 正月-394`，日序为负数）|
| 年份 > 2100（如 2101） | **抛运行期错误**（实测消息 `tuple index out of range`）|

补充边界：

- `干支纪年` / `生肖` 是纯取模运算，任意年份都会返回结果且形式正确，
  但**不做农历年首（春节）边界修正**：公历 1 月 1 日至春节之间的日期，
  其干支/生肖按公历年份计算，与传统「农历年」口径不一致。
  例：本示例中 2026-01-01 显示为「丙午年 属马」，而传统农历此时仍属乙巳蛇年
- 节气名表在 `历法.py` 中已定义，但**尚无对外的节气查询动词**，
  本示例中「清明」只是日程条目名，不是节气计算结果
- 农历闰月由 `公历转农历` 的第四个返回值标记，`农历完整日期` 的中文串
  不显式标注「闰」字
