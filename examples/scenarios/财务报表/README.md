# 场景：财务报表自动处理

## 用途

演示极快在**财务报销**场景下的一体化能力：用人民币精确金额（`￥` 字面量，按分存储不失真）录入多笔报销明细，自动完成小计、增值税、含税合计的计算，输出中文大写金额，并用逗号管道对明细做筛选（大额支出）与聚合（求和、折扣核减）。适合作为「中国特色 + 管道范式」的综合样例。

## 输入

全部为**固定字面量**，内嵌在 `main.jk` 中，无需外部数据文件，因此输出可作稳定快照：

- 差旅费 ￥1280.00
- 餐饮费 ￥356.50
- 办公费 ￥89.90
- 设备费 ￥4599.00
- 通讯费 ￥128.00
- 培训费 ￥680.00
- 税率：6%（增值税）
- 大额门槛：￥500.00
- 核减折扣：9 折

## 预期输出

见同目录 `expected.txt`（真实运行结果的快照）。要点：

- 报销小计 ￥7133.40，增值税 ￥428.00，含税合计 ￥7561.40
- 大写金额：小计「柒仟壹佰叁拾叁元肆角」，合计「柒仟伍佰陆拾壹元肆角」
- 大额支出（>￥500）筛出 3 笔，合计 ￥6559.00
- 9 折核减后逐笔金额与合计
- 逐笔中文大写清单

## 前置依赖

- Python 3.8+，仓库根目录下运行
- 运行方式：`PYTHONPATH=src python -m jikuai examples/scenarios/财务报表/main.jk`
- 不依赖任何标准库 `.jk` 模块，只用内建动词（`求和` `长度` `拼接` `转字符串` `大写金额`）与逗号管道（`只大于` `皆乘`）
