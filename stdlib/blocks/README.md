# stdlib/blocks · 块生态目录

本目录存放极快 v0.12.0 起引入的**块**（Block）——带 `块.json` 元数据的 `.jk`
模块。块按**领域**组织，v0.12.0 首批四个领域：

- `数据/` —— 文件读写、列表处理、聚合统计
- `中文/` —— 分词、简繁、农历、人民币等中国特色场景
- `网络/` —— HTTP、JSON、URL、限流重试
- `工具/` —— 日志、时间戳、UUID、路径、断言

组合块**不引入新语法**，直接用现有的 `导入` 语句、逗号 `，` 管道与函数调用。

详见 [`docs/块生态.md`](../../docs/块生态.md)。
