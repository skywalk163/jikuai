## 2. 架构决策（架构师）

| ADR | 决策 | 理由 |
| --- | --- | --- |
| **ADR-01** | T-01 采用 **lexer 预扫描扩展**（`_prescan_definitions` 加扫 `函数` / `方法` / `类`），而非语法制导切分 | 对现有状态机零侵入；与 `定义` 共用 `_try_user_def` 白名单路径；白名单是全局集合，**天然覆盖调用点**，无需单独处理调用上下文 |
| **ADR-02** | T-02 引入 `ClassDef.ctor_defined: bool` 布尔标志区分「未定义构造器」与「空构造器体」，而非把 `ctor_body` 改为 `Optional` | 布尔语义显式，对现有读取 `ctor_body` 的代码零破坏 |
| **ADR-03** | REPL 多行判定复用 **lexer 闭合态 + parser 特化异常 `UnexpectedEOFError`**，而非 REPL 自行数括号 | 单一事实源；语言语法演进时 REPL 无需同步改动 |
| **ADR-04** | 未初始化字段返回 nil **仅限「已声明字段」**，未声明属性仍报错 | 避免 nil 保护掩盖拼写错误（typo） |
| **ADR-05** | Tab 补全采用**三源合并**（`ALL_KEYWORDS ∪ VERB_ARITY ∪ global_env.vars`），不做语法感知过滤 | 定位是 REPL 增强，非 IDE 智能感知，避免过度工程 |

### 2.1 ADR-03 的实现期修订（须留痕）

ADR-03 原文为「lexer 闭合态 **+** parser 特化异常**组合**判定」。工程师首轮偏向依赖 lexer 侧 net `block_depth` 归零，引发阻塞缺陷 D-01。经交付总监裁决，返工后收敛为**纯 parser 权威判定**，lexer 侧 `ClosureState` 完全删除。

**最终生效的判定真值表**：

| `parse(buffer)` 结果 | 判定 | REPL 行为 |
| --- | --- | --- |
| 抛 `UnexpectedEOFError` | 未闭合 | 显示 `...`，继续收集 |
| 成功 | 完整 | 立即执行 |
| 抛其他语法错误 | 真错误 | 输出中文诊断，清空缓冲 |

**唯一例外**：lexer 层「未闭合字符串」在 tokenize 阶段即抛错，parser 拿不到 token。QA 核定该例外与真值表相容，已在代码注释与 `CHANGELOG.md` 中说明。

> 行动项：ADR-03 应更新为 **ADR-03a**，将「组合判定」修正为「纯 parser 权威 + 未闭合字符串 lexer 例外」，并纳入 ASCII 逗号追认登记。见第 8 章 A-1。

### 7.3 风险提示

1. **兼容性风险（中）**：`_require_block_close()` 带来的行为收紧对项目内 11 个示例无影响，但**外部既有脚本**若省略块末 `。` 将从「静默通过」变为「报错」。A-2 未完成前不得发布。
2. **T-01 作用域残缺（中）**：D-04/D-09 证明 T-01 的白名单方案只覆盖了函数名与类名，方法名与关键字内嵌两条路径仍缺失。本轮 AC-32 达标属**范围内达标**，不等于问题根因已彻底消除，须在 v0.3.1 补齐，避免用户形成「T-01 已完全解决」的错误预期。
3. **测试覆盖信心（低，已缓解）**：本轮出现过「98/98 全绿但存在阻塞缺陷」的情况，绿灯数不能单独作为质量证据。已由 A-6 与 QA 独立探针机制缓解。
4. **单一事实源依赖（低）**：续行判定现完全依赖 parser 抛 `UnexpectedEOFError`。今后**任何新增块结构语法都必须同步调用 `_require_block_close()`**，否则 REPL 续行会静默失效。建议在 parser 中以注释或测试形式固化该约定。
