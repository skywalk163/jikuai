# AGENTS.md 行为效力对照台架

回答一个问题：**AGENTS.md 第四节（检索不拒答那段）是否真的改变 agent 行为？**

不是 CI 门禁——被测对象是**真实 agent**，要人开三个独立会话跑。改了 AGENTS.md 第四节
就该重跑一遍，否则等于凭感觉写文档。

## 为什么不能用 subagent 跑

首次尝试用 subagent 做对照臂，探针直接失败：本仓库的 AGENTS.md 会通过 matched-rules
**全文注入**每个 subagent，`MEMORY.md` 索引和 `git log` 里也有拒答专题的痕迹。也就是说
在这个仓库里派出的任何 subagent 都**天然是「有 AGENTS.md」臂**，裸协议臂造不出来，
「只给规则」臂也会被全文盖掉。

所以三臂必须在**仓外空目录**（如 `G:\tmp\jikuaiagent`）的**三个互相独立的新会话**里跑。

## 三臂

- **A 裸协议** `手册_A_裸协议.md`：只有协议与字段说明，无任何拒答/覆盖边界提示。
- **B 全文**：直接用仓库根的 `AGENTS.md`（构建时自动读取，不用另存副本）。
- **C 只给规则** `手册_C_只给规则.md`：规则 + 模块陷阱表，删掉黑名单与实例表。

## 样本（`用例集.json`，35 条）

- `N1` 明示负例 7：AGENTS.md 点过名的近边缘负例（开卷档，量顺从度地板）
- `N2` 未明示负例 12：按 112 块清单逐域反推的兄弟能力缺位，AGENTS.md 未点名（**载荷集**，量规则可迁移性）
- `P` 正例 12：来自 `评测集.json`（量过度弃用/误弃——没有它，一律回答「自己写」就能满分）
- `M` 模块档 3：能力在 `stdlib/*.jk` 但选块永不返回（量陷阱表效力，正确答案是「用模块」）
- `争议` 1：`无形资产每年摊销多少`，标签本身站不住，单列不计入有害组装率

标签与判据只在 `用例集.json`，**绝不能放进被测会话可读的目录**。提示词里用中性编号
`Q01..Q35` 且顺序打散，被测 agent 看不出档位。

## 跑法

```powershell
# 1. 抓刺激（35 条选响应，三臂共用同一份，保证刺激完全一致）
g:\jikuai\.venv\Scripts\python.exe 抓刺激.py

# 2. 生成三臂提示词（prompts/ 是生成物，不入库）
g:\jikuai\.venv\Scripts\python.exe 构建判分.py 构建 --阶段 全量   # 或 --阶段 试点

# 3. 逐臂跑：把 prompts/提示_{A|B|C}_全量.txt 复制成 <仓外目录>\任务.txt
#    换臂后先核 MD5 再开会话——口头声称换过而实际没换，会让整臂白跑
Get-FileHash <仓外目录>\任务.txt -Algorithm MD5
#    在新会话里发两句：先问它上下文有没有提到极快/jikuai/AGENTS.md（探针，应答「无」），
#    再让它「读 任务.txt，按里面的要求执行」。它会写出 回答.json。
#    收走 回答.json → answers\回答_{臂}_{阶段}.json，并从仓外目录删掉，再换下一臂。

# 4. 判分（分档报数 + 逐条三臂对照）
g:\jikuai\.venv\Scripts\python.exe 构建判分.py 判分 --阶段 全量
```

`静态核查.py` 是配套的零成本检查：每条负例的兄弟块，描述里有没有在**需求变动的那个
维度**上自报口径。没有自报，「看描述限定词」这条规则就物理上无法触发。

## 2026-08-15 首轮结论

**臂A 30/34 · 臂B 34/34 · 臂C 34/34**（争议档单列）。臂A 跑了两次采样，35/35 判定完全一致。

- **裸协议基线远比「零拒答」暗示的高**：臂A 无任何提示下 N1 7/7、N2 11/12、P 12/12
  不误弃，且 35/35 全部自发 `依据=描述`，一次没碰分数。`retrieve()` 零拒答是**检索层**
  事实，**agent 判断层不上当**——`bench_retrieval_reject.py` 那个 0.0% 量的是检索器，不是 agent。
- **净收益 +4 条，全部可归因**：模块陷阱表 3 条（银行卡/社会信用代码/车牌，A 全判自己写去
  重写 Luhn，B/C 全判用模块），规则本身 1 条（按成绩排名次，A 误用 `降序` 块，B/C 都弃用；
  臂C 没有黑名单也对，说明规则能独立起作用）。
- **黑名单 + 6 行实例表真收益 0 条**：臂C == 臂B 但短 3500 字符。唯一独有贡献是争议那条
  （无形资产摊销），而 `折旧` 块残值传 0 出来就是正确的直线摊销额——那是**文档制造的误弃**。
  据此已砍掉黑名单与实例表，并把该条从 `评测集-近边缘-留出.json` 移除。
- **规则「别看分数」反而把分数推进了推理**：臂A 全程没提分数，臂B 却在 IRR 那条写
  「分数普遍低于 0.7 也印证无覆盖」——正是被禁止的用法（数字属实、方向也对，属侥幸命中）。
  规则已改成中性表述。

**局限**：单一 agent 实现不外推；刺激预抓，所以不测「agent 会不会主动翻 `stdlib/` 自己
发现 `校验.jk`」，M 档只反映陷阱表的作用；N2 由读过 AGENTS.md 的人造题，有贴题风险；
三臂差异只有 4 条，是个案级证据不是分布级。
