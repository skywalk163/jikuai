# 极快（jikuai）调用手册

极快（`.jk`）是一个确定性代码合成层：从 112 个块的库里挑几个块，用模板 + 类型图推导
拼出粘合代码，整条链路不调用任何 LLM。把「生成几百行 + 反复调试」换成「选几个块 +
填参数」。

块库分六个领域：财务 / 数据 / 中文 / 历法 / 网络 / 工具，内容偏中国式业务（人民币、
个税、增值税、农历、干支、身份证、报销单、工资册、客户对账）。

## 三连（机读接口）

三条命令，退出码约定 `0` 成功 / `1` 输入错误 / `2` 执行期报错。

```bash
jk 块 选 "月薪两万个税多少" --json    # → 选响应
jk 块 组 方案.json                    # → {"源码": "..."}
jk 块 跑 方案.json --json             # → 跑响应
```

`选响应`：

```json
{
  "需求": "月薪两万个税多少",
  "候选": [
    {"名称": "个税", "领域": "财务", "层级": 0, "导出名": "缴税",
     "描述": "中国大陆个人所得税月度速算，起征点5000，七级超额累进（2019年起适用）",
     "分数": 3.5901, "路径": "[启发式]"}
  ]
}
```

- `名称` 是块目录名，`导出名` 是调用名，两者可以不同（`个税` 块导出 `缴税`）。
  写导入语句一律用 `导出名`：`从 blocks.财务.个税 导入 缴税。`
- `描述` 是块作者写的功能说明。
- `分数` 是未归一化的 TF-IDF 相关度，跨查询不可比。不要拿它当置信度，理由见下一节。
- `路径` 是 `[启发式]` 或 `[神经]`。可选字段 `降级说明` 只在请求神经检索却拿不到
  查询向量时出现。可选字段 `命名空间` 只在第三方块包里出现。
- `层级` 是块的组合深度：0 是原子块，1 以上是由更低层块拼出来的复合块。

`方案.json`（你要构造的输入）：

```json
{
  "需求": "月薪两万个税多少",
  "共享": [{"名": "赵月收", "值": "20000"}],
  "步骤": [
    {"块": "个税", "领域": "财务", "导出名": "缴税", "参数": ["赵月收"]}
  ]
}
```

`步骤.参数` 省略时，粘合器按类型图 + 槽名字面匹配自动推链。协议禁止多余字段，多一个
键就报错。

`跑响应`：`{"源码": "...", "执行结果": {"stdout", "stderr", "返回值", "耗时毫秒",
"错误"?, "诊断"?}}`。

## 最重要的一条：这个工具不会说「我不知道」

检索**没有分数阈值、没有拒答路径**，永远返回 top-K。库里根本没有对应能力时，它照样
返回几个像样的中文块名和一个高分。实测：明确无覆盖的需求，返回空候选 0 条，正确拒答率
0.0%。

最危险的是**贴着覆盖边缘**的需求——措辞像块术语、语义却没覆盖。这种情况下你照着候选
组出来的代码**会跑通，但结果是错的**。

已有多轮实测证伪了所有基于分数的自动拒答方案：近边缘需求上，各置信信号的可分性 AUC
只有 0.52–0.67（0.5 = 随机），唯一能拒掉 94% 无覆盖需求的阈值会同时误杀 64% 的
真命中。所以**这个判断没法自动化，只能由你做**。

### 因此你必须遵守

1. **每次拿到候选，先自己判断它是否真的做这件事**。看 `描述`，不要看 `分数`。
   `描述` 写的是精确口径（「月度速算」「直线法」「固定资产」），别放过限定词。
2. **需求里有块描述没覆盖的关键词，就当没命中**。这些限定词是判据。
3. **没命中就自己写代码**，别硬凑。凑出来的是「跑得通但算错」，比报错糟得多。
4. **涉及钱、税、社保、工资的需求，宁可自己写 + 补测试**。这类错误在运行期不报错，
   只在审计时暴露。
5. `jk 块 组` 的源码里出现 `?` 占位或 `需人工填参` 记号，表示粘合器推不出实参并
   **拒绝硬塞**（它把拒绝理由写进源码注释）。这是设计如此，不是 bug——照注释补参数，
   或者判断这条路走不通就换自己写。

### 陷阱：块库 ≠ stdlib 模块，`选块` 只搜块

`jk 块 选` 检索的是 `stdlib/blocks/` 下的 112 个**块**。极快还有另一套能力面——
`stdlib/*.jk` **模块**，`选块` **永远不会返回它们**：

| 模块 | 导出 |
| --- | --- |
| 校验 | 校验身份证、校验手机号、**校验银行卡**、**校验车牌**、**校验社会信用代码** |
| 正则 | 匹配、搜索、替代、编译 |
| 简繁 | 转繁体、转简体 |
| 排版 | 规范化文本、插入间距、规范标点 |
| 成语 | 是成语、成语释义 |
| 分词 | 分词 |
| 工具 | 平方、立方 |

所以「选块没命中」**不等于**「极快没有这个能力」。上表里的东西直接 `从 校验 导入
校验银行卡。` 用，别自己重写。判断顺序应该是：先查上表 → 再 `jk 块 选` → 都没有才自己写。

## 其它入口

Python 库（`import jikuai` 无副作用、无全局可变状态）：

```python
import jikuai
mod = jikuai.load("脚本.jk")       # 模块对象
jikuai.run_source('打印 加 3 5。')
# 异常 jikuai.JiKuaiError，e.info 是 ErrorInfo（保留中文文案）
```

LSP（`python -m jikuai_lsp`）有 `workspace/executeCommand` 命令 `极快.选块`，
入参 `{需求, top?}`，出参与 `jk 块 选 --json` 同构。上一节的限制同样适用。

包管理：`jk 包 <初始化|添加|装|列表|运行|发布|密钥|搜索|注册表>`。

要执行代码，用 `jk 块 组` 拿源码，然后跑 `jk <文件.jk>`。
