# 《块选择协议 v0》

把「用户自然语言需求」映射为「一组块的选择 + 参数」，再由粘合器合成可运行极快代码。

## 数据流

```
用户需求（字符串）
      │
      ▼
[选块]  select.py：本地关键词匹配（v0 不外接大模型）
      │
      ▼
选块方案（JSON，本文件定义结构）
      │
      ▼
[粘合]  glue.py：合成极快源码
      │
      ▼
可运行极快代码 → python -m jikuai / run_source
```

v0 用**本地关键词匹配**做「选块」这一步——先把协议跑通。真正的语义选择
（理解「求和再算平均」= 求和块 + 均值块）留 v0.13.0。

## 选块方案 JSON 结构

```json
{
  "需求": "把一批数字求和再算平均",
  "共享": [
    {"名": "赵料", "值": "列 100 200 150 300 250"}
  ],
  "步骤": [
    {"块": "求和", "领域": "数据", "导出名": "汇总", "说明": "对列表求和", "参数": ["赵料"]},
    {"块": "均值", "领域": "数据", "导出名": "中位", "说明": "算平均",   "参数": ["赵料"]}
  ],
  "打印": ["赵果1", "赵果2"]
}
```

### 字段定义

| 字段 | 必填 | 类型 | 说明 |
|------|------|------|------|
| `需求` | 否 | string | 原始自然语言需求，仅作生成代码里的注释 |
| `共享` | 否 | array | 前置常量/输入定义，先于步骤生成 `定义<名>=<值>。` |
| `共享[].名` | 是 | string | 变量名，须**词法原子**（整体是单个 IDENT，见 ADR-15 §3.7） |
| `共享[].值` | 是 | string | 极快表达式片段，如 `列 1 2 3` 或 `"文本"` |
| `步骤` | 是 | array | 至少一个步骤 |
| `步骤[].块` | 是 | string | 块的**目录名**（索引里的 `名称`），用于 `导入` 语句 |
| `步骤[].领域` | 是 | string | 块所属领域（数据/中文/网络/工具） |
| `步骤[].导出名` | 是 | string | 块的**导出名**，用于调用；由 `extract_exports` 从 `.jk` 得到 |
| `步骤[].说明` | 否 | string | 该步骤的注释 |
| `步骤[].参数` | 否 | array | 调用实参（每项是极快表达式片段）。缺省则生成占位符 `?` 并注释「需人工填参」 |
| `打印` | 否 | array | 要打印的变量名。缺省则打印每步结果变量（`赵果1`、`赵果2`…） |

### 关于「导入用目录名、调用用导出名」

ADR-15 §3.7 规定：

```jikuai
从 blocks.数据.求和 导入 汇总。   -- 导入语句用目录名「求和」
打印 汇总(列 1 2 3 4 5)。          -- 调用用导出名「汇总」
```

所以方案里 `块`（目录名）与 `导出名` 是两个不同字段。选块器负责把二者一并填好：
`块` 来自索引 `名称`，`导出名` 由 `jikuai.pkg.blocks.extract_exports` 从对应
`.jk` 文件里提取（索引本身**不含**导出名字段）。

## 粘合器生成规则（glue.synthesize）

1. 顶部注释：`-- 由 极快 AI 桥接 v0 ... 自动合成` + `-- 需求：...`
2. 为每个步骤生成一行 `从 blocks.<领域>.<块> 导入 <导出名>。`（去重）
3. `共享` 定义逐条生成 `定义<名>=<值>。`
4. 步骤逐个生成 `定义赵果N=<导出名>(<参数空格拼接>)。`
   - 无 `参数` → 实参写 `?`，上一行加注释「需人工填参」
5. `打印` 列表（或默认每步结果变量）逐条生成 `打印 <名>。`

## v0 局限（务必知晓）

- **选块靠字符重叠**：同义改写（「加总」vs「求和」）可能命中不到。
- **参数不自动推断**：v0 需要方案显式给 `参数`；否则生成 `?` 占位符，代码跑不通。
- **链式传参靠人工**：把上一步结果喂给下一步，需在 `参数` 里手写 `赵果1` 这类变量名。
- **无类型校验**：把字符串喂给需要列表的块，要到运行期才报错。

这些正是 v0.13.0 要用「语义选择 + 类型对齐」补上的部分。
