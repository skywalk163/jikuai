等价 SQL 逐步对照表
============================================================
需求：【数据质量检查】fact_orders 订单事实表体检：报出空值列与计数、主键 order_id 重复数、两条外键（model_id→dim_model、customer_id→dim_customer）的孤儿行数。复用 质量体检 块，不新增块。
方言：ANSI SQL（只作展示，本工具从不执行，也不连接任何数据库）
覆盖：1/2 步登记了等价 SQL

------------------------------------------------------------
第 1 步 · 表载入 → 读表
  .jk ：定义赵果1=读表(赵订单路)。
  SQL ：
        SELECT *
        FROM fact_orders

------------------------------------------------------------
第 2 步 · 质量体检 → 体检
  .jk ：定义赵果2=体检(赵果1 赵主键组 赵外键检查)。
  SQL ：未登记 —— 输出是四元组 [行数, 空值列与计数, 主键重复数, 外键孤儿行数]，不是一张表。四项互不同构（两项还是字典），硬塞成一条 SELECT 会把它伪装成一行数据——那比没有 SQL 糟。

============================================================
无 WITH 链全文：有 1 步没有等价 SQL（质量体检），因此不出 WITH 全文——半截 SQL 会被误当成「能跑的那份」。
