# 制造业运营态势 Chat BI Agent 模拟数据集

## 数据定位

本数据集为赛事方可发布的模拟制造业经营数据集，覆盖订单、生产计划、生产实绩、质量缺陷、能源消耗、车型、产线、客户等业务对象。

数据时间范围：2026-01-01 至 2026-06-30。

## 预置业务异常

1. 2026年6月，M003（中卡C型）在 L002（焊装一线）出现明显质量异常，主要集中在“焊装-焊点虚焊”。
2. 2026年6月10日至6月24日，L002（焊装一线）单车电耗明显升高。
3. 2026年6月，客户 C005 的 M003 订单集中延期。
4. L003（总装二线）夜班达成率持续低于白班。
5. 2026年4月8日至4月18日，L005（总装三线）停线时长偏高。

## 参赛建议

参赛团队可基于本数据集构建 Chat BI Agent，实现自然语言问数、Text-to-SQL、图表生成、运营日报和异常解释。

公开问题集用于参赛者自测；隐藏问题集建议由赛事方保留，用于统一评审。
